テストTestingစမ်းသပ်ခြင်း 77語77 wordsစကားလုံး 77 လုံး

  • 単体試験UT たんたいしけん Unit testing ပရိုဂရမ်ရဲ့ အစိတ်အပိုင်းတစ်ခုချင်းစီကို သီးခြားစမ်းသပ်ခြင်း
  • 結合試験IT けつごうしけん Integration testing အစိတ်အပိုင်းများကို ပေါင်းစပ်ပြီး အတူတကွ မှန်ကန်စွာ အလုပ်လုပ်မလုပ် စမ်းသပ်ခြင်း
  • 総合試験ST そうごうしけん System testing စနစ်တစ်ခုလုံးကို လိုအပ်ချက်များနှင့်အညီ အလုပ်လုပ်မလုပ် စမ်းသပ်ခြင်း
  • 不具合 ふぐあい Defect ပရိုဂရမ်ထဲက ချို့ယွင်းချက် (bug)
  • 試験仕様書 しけんしようしょ Test specification စမ်းသပ်မည့် အကြောင်းအရာ၊ လုပ်ဆောင်ပုံနှင့် မျှော်မှန်းရလဒ်များကို ရေးထားသော စာရွက်စာတမ်း
  • テストケースTC てすとけーす Test case စမ်းသပ်မည့် အခြေအနေနှင့် မျှော်မှန်းရလဒ် တစ်ခုချင်းစီ
  • 試験項目 しけんこうもく Test item စမ်းသပ်ရမည့် အချက်တစ်ခုချင်းစီ
  • エビデンス えびでんす Test evidence စမ်းသပ်ပြီးကြောင်း သက်သေပြသည့် screenshot သို့မဟုတ် log
  • 回帰試験 かいきしけん Regression testing ပြင်ဆင်ပြီးနောက် ယခင်အလုပ်လုပ်ခဲ့သော အပိုင်းများ ပျက်မသွားကြောင်း ပြန်စမ်းသပ်ခြင်း
  • 負荷試験 ふかしけん Load testing အသုံးပြုသူ အများအပြား တစ်ပြိုင်နက် သုံးသည့်အခါ စနစ် ခံနိုင်မခံနိုင် စမ်းသပ်ခြင်း
  • 性能試験 せいのうしけん Performance testing စနစ်၏ တုံ့ပြန်ချိန်နှင့် အမြန်နှုန်းကို စမ်းသပ်ခြင်း
  • 受入試験UAT うけいれしけん Acceptance testing ဖောက်သည်ဘက်က စနစ်ကို လက်ခံမခံ စစ်ဆေးသည့် စမ်းသပ်မှု
  • 境界値 きょうかいち Boundary value အကန့်အသတ်၏ အစွန်းဆုံးတန်ဖိုး (ဥပမာ အများဆုံး၊ အနည်းဆုံး)
  • 正常系 せいじょうけい Normal case ပုံမှန်အတိုင်း မှန်ကန်စွာ လုပ်ဆောင်သည့် ဖြစ်စဉ်
  • 異常系 いじょうけい Error case အမှားဖြစ်သည့် သို့မဟုတ် ပုံမှန်မဟုတ်သည့် ဖြစ်စဉ်
  • 再現手順 さいげんてじゅん Steps to reproduce ပြဿနာကို ပြန်ဖြစ်အောင် လုပ်ရမည့် အဆင့်များ
  • 再現 さいげん Reproduce (a bug) ပြဿနာကို ထပ်မံဖြစ်ပေါ်အောင် လုပ်ခြင်း
  • 期待値 きたいち Expected result ဖြစ်သင့်သည့် ရလဒ် (မျှော်မှန်းရလဒ်)
  • 不具合票 ふぐあいひょう Bug report ချို့ယွင်းချက်ကို မှတ်တမ်းတင်သည့် စာရွက် သို့မဟုတ် ticket
  • 起票 きひょう Filing a ticket ticket သို့မဟုတ် ပြဿနာမှတ်တမ်းအသစ် ဖွင့်ခြင်း
  • 修正確認 しゅうせいかくにん Fix verification ပြင်ဆင်ထားသည့်အရာ မှန်ကန်ကြောင်း ပြန်စစ်ခြင်း
  • デグレ でぐれ Regression (bug) ပြင်ဆင်မှုကြောင့် ယခင်အလုပ်လုပ်ခဲ့သည့် လုပ်ဆောင်ချက် ပျက်သွားခြင်း
  • 切り分け きりわけ Isolating the cause ပြဿနာ၏ အကြောင်းရင်း ဘယ်အပိုင်းမှာ ရှိသလဲ ခွဲခြားရှာဖွေခြင်း
  • 暫定対応 ざんていたいおう Temporary fix အမြန်ဖြေရှင်းရန် ယာယီလုပ်ဆောင်ချက်
  • 恒久対応 こうきゅうたいおう Permanent fix ပြဿနာ ထပ်မဖြစ်အောင် အမြဲတမ်း ဖြေရှင်းချက်
  • カバレッジ かばれっじ Code coverage စမ်းသပ်မှုဖြင့် ကုဒ်၏ ဘယ်နှစ်ရာခိုင်နှုန်းကို ဖြတ်သန်းခဲ့သလဲ ပြသသည့်နှုန်း
  • 自動テスト じどうてすと Automated testing ပရိုဂရမ်ဖြင့် အလိုအလျောက် လုပ်ဆောင်သော စမ်းသပ်မှု
  • 疎通確認 そつうかくにん Connectivity check စနစ်နှစ်ခုကြား ချိတ်ဆက်နိုင်မနိုင် စစ်ဆေးခြင်း
  • 動作確認 どうさかくにん Operation check ပရိုဂရမ် မှန်ကန်စွာ အလုပ်လုပ်မလုပ် စမ်းကြည့်ခြင်း
  • テストデータ てすとでーた Test data စမ်းသပ်ရန်အတွက် ပြင်ဆင်ထားသော ဒေတာ
  • モック もっく Mock အစစ်အမှန်အစား စမ်းသပ်ရန် သုံးသော အတု object
  • 品質 ひんしつ Quality အရည်အသွေး
  • 指摘 してき Review comment ပြန်လည်သုံးသပ်စဉ် ထောက်ပြသည့် အချက် (ပြင်ရန်အချက်)
  • 消化率 しょうかりつ Test completion rate စမ်းသပ်ရမည့်အချက်များအနက် ပြီးစီးသွားသည့် ရာခိုင်နှုန်း
  • 合否 ごうひ Pass/fail အောင်/ကျ ရလဒ်
  • 原因調査 げんいんちょうさ Root cause investigation ပြဿနာ၏ အကြောင်းရင်းကို စုံစမ်းရှာဖွေခြင်း
  • 試験環境 しけんかんきょう Test environment စမ်းသပ်ရန်အတွက် ပြင်ဆင်ထားသော ပတ်ဝန်းကျင်
  • 目視確認 もくしかくにん Visual check မျက်စိဖြင့် ကြည့်ပြီး စစ်ဆေးခြင်း
  • テスト観点 てすとかんてん Test perspective ဘာကို စမ်းသပ်ရမလဲဆိုသည့် ရှုထောင့်/အချက်
  • 網羅 もうら Coverage (completeness) အားလုံးကို ချန်မထားဘဲ ပါဝင်စေခြင်း
  • 打鍵 だけん Manual operation testing screen ပေါ်တွင် လက်ဖြင့် ရိုက်/နှိပ်၍ စမ်းသပ်ခြင်း
  • 突合 とつごう Reconciliation (comparing data) ဒေတာနှစ်ခုကို တိုက်ဆိုင်စစ်ဆေးခြင်း
  • 証跡 しょうせき Evidence (formal) လုပ်ဆောင်ခဲ့ကြောင်း သက်သေ မှတ်တမ်း
  • 実機 じっき Real device emulator မဟုတ်သော အစစ်အမှန် ဖုန်း/စက်
  • 再試験 さいしけん Retest မအောင်မြင်သော စမ်းသပ်မှုကို ပြင်ပြီးနောက် ထပ်စမ်းခြင်း
  • 収束 しゅうそく Convergence (bugs settling) ချို့ယွင်းချက်အသစ်များ လျော့နည်းလာပြီး တည်ငြိမ်လာခြင်း
  • リリース判定 りりーすはんてい Release decision release လုပ်နိုင်/မနိုင် ဆုံးဖြတ်ခြင်း
  • ブラウザ確認 ぶらうざかくにん Browser check browser အမျိုးမျိုးတွင် မှန်ကန်စွာ ပြမပြ စစ်ဆေးခြင်း
  • ペネトレーションテスト ぺねとれーしょんてすと Penetration test တိုက်ခိုက်သူအမြင်ဖြင့် စနစ်ကို ဖောက်ဝင်ကြည့်ပြီး စစ်ဆေးခြင်း
  • 表示崩れ ひょうじくずれ Broken layout စာမျက်နှာ ပုံစံ ပျက်ယွင်းစွာ ပြခြင်း
  • 画面回転 がめんかいてん Screen rotation ဖုန်းကို လှည့်သောအခါ screen လှည့်ခြင်း
  • テスト計画 てすとけいかく Test plan test ၏ ရည်ရွယ်ချက်၊ အချိန်၊ နည်းလမ်း စသည်ကို ရေးထားသော စာ
  • テスト設計 てすとせっけい Test design ဘာကို ဘယ်လို test လုပ်မည်ကို ဒီဇိုင်းဆွဲခြင်း
  • テスト実施 てすとじっし Test execution test ကို တကယ် လုပ်ဆောင်ခြင်း
  • テスト結果 てすとけっか Test results test ၏ ရလဒ်
  • 試験成績書 しけんせいせきしょ Test report test ရလဒ်ကို တရားဝင် စုစည်းထားသော စာရွက်
  • 不具合管理 ふぐあいかんり Defect management ချို့ယွင်းချက်များကို မှတ်တမ်းတင် စီမံခြင်း
  • 再現性 さいげんせい Reproducibility ပြဿနာ ထပ်ခါ ဖြစ်စေနိုင်မှု
  • 発生頻度 はっせいひんど Frequency of occurrence ပြဿနာ မည်မျှ မကြာခဏ ဖြစ်သည်
  • 致命的 ちめいてき Critical (fatal) စနစ်ကို အသုံးမပြုနိုင်လောက်အောင် ပြင်းထန်သော
  • 軽微 けいび Minor သေးငယ်သော၊ အရေးမကြီးသော
  • 重大 じゅうだい Serious အလွန် အရေးကြီး ပြင်းထန်သော
  • 修正漏れ しゅうせいもれ Missed fix ပြင်ရမည့်နေရာကို ပြင်ရန် ကျန်ခဲ့ခြင်း
  • 確認漏れ かくにんもれ Missed check စစ်ဆေးရန် ကျန်ခဲ့ခြင်း
  • 仕様通り しようどおり As specified spec တွင် ရေးထားသည့်အတိုင်း
  • 仕様バグ しようばぐ Specification bug spec ကိုယ်တိုင်တွင် အမှားပါနေခြင်း
  • 想定外 そうていがい Unexpected ကြိုတင် မမျှော်လင့်ထားသော
  • 想定通り そうていどおり As expected ကြိုတင် မျှော်လင့်ထားသည့်အတိုင်း
  • 探索的テスト たんさくてきてすと Exploratory testing test case မပါဘဲ စမ်းသပ်ရင်း ပြဿနာရှာခြင်း
  • ブラックボックステスト ぶらっくぼっくすてすと Black-box testing code အတွင်းပိုင်းကို မကြည့်ဘဲ input/output ဖြင့် စစ်ခြင်း
  • ホワイトボックステスト ほわいとぼっくすてすと White-box testing code အတွင်းပိုင်းကို ကြည့်ပြီး logic လမ်းကြောင်းများကို စစ်ခြင်း
  • 組み合わせ くみあわせ Combination အရာများကို တွဲပေါင်းခြင်း
  • 同値分割 どうちぶんかつ Equivalence partitioning input များကို တူညီသော အုပ်စုများခွဲ၍ test လုပ်ခြင်း
  • 品質基準 ひんしつきじゅん Quality criteria အရည်အသွေး ပြည့်မီရမည့် စံနှုန်း
  • 合格基準 ごうかくきじゅん Pass criteria test အောင်ရန် စံနှုန်း
  • バグ密度 ばぐみつど Bug density code ပမာဏ တစ်ခုစီရှိ bug အရေအတွက်
  • テスト密度 てすとみつど Test density code ပမာဏ တစ်ခုစီရှိ test case အရေအတွက်
