設計Designဒီဇိုင်း 101語101 wordsစကားလုံး 101 လုံး

  • 仕様書 しようしょ Specification စနစ်ရဲ့ လုပ်ဆောင်ချက်များကို ရေးသားဖော်ပြထားတဲ့ စာတမ်း
  • 基本設計BD きほんせっけい Basic design အသုံးပြုသူဘက်က မြင်ရတဲ့ စနစ်ရဲ့ အခြေခံဒီဇိုင်း
  • 詳細設計DD しょうさいせっけい Detailed design ပရိုဂရမ်ရေးရန်အတွက် စနစ်အတွင်းပိုင်းကို အသေးစိတ်ဒီဇိုင်းဆွဲခြင်း
  • 要件定義RD ようけんていぎ Requirements definition ဖောက်သည်လိုအပ်ချက်များကို ရှင်းလင်းစွာ သတ်မှတ်ခြင်း
  • 外部設計 がいぶせっけい External design အသုံးပြုသူဘက်က မြင်ရသည့် အပိုင်း (မျက်နှာပြင်၊ စာရွက်စာတမ်း၊ ချိတ်ဆက်မှု) ကို ဒီဇိုင်းဆွဲခြင်း
  • 内部設計 ないぶせっけい Internal design စနစ်အတွင်းပိုင်း ဖွဲ့စည်းပုံနှင့် လုပ်ဆောင်ပုံကို ဒီဇိုင်းဆွဲခြင်း
  • 画面設計 がめんせっけい Screen design မျက်နှာပြင်၏ layout နှင့် item များကို ဒီဇိုင်းဆွဲခြင်း
  • 画面遷移図 がめんせんいず Screen flow diagram မျက်နှာပြင်တစ်ခုမှ တစ်ခုသို့ ကူးပြောင်းပုံကို ပြသည့် ပုံ
  • 帳票 ちょうひょう Business form / report ပုံနှိပ်ထုတ်သော လုပ်ငန်းသုံး ပုံစံ (ပြေစာ၊ အစီရင်ခံစာ စသည်)
  • ER図ERD いーあーるず ER diagram ဒေတာဘေ့စ် table များနှင့် ၎င်းတို့ ဆက်စပ်ပုံကို ပြသည့် ပုံ
  • テーブル定義書 てーぶるていぎしょ Table definition document ဒေတာဘေ့စ် table ၏ column၊ type စသည်ကို ရေးထားသော စာတမ်း
  • 項目定義 こうもくていぎ Field definition item တစ်ခုချင်းစီ၏ အမည်၊ အမျိုးအစား၊ အရှည် စသည် သတ်မှတ်ချက်
  • 設計書 せっけいしょ Design document ဒီဇိုင်းအကြောင်း ရေးထားသော စာတမ်း
  • 方式設計 ほうしきせっけい Architecture design စနစ်တစ်ခုလုံး၏ နည်းပညာ ဖွဲ့စည်းပုံကို ဒီဇိုင်းဆွဲခြင်း
  • アーキテクチャ あーきてくちゃ Architecture စနစ်တစ်ခု၏ အဓိက ဖွဲ့စည်းပုံ
  • 機能要件 きのうようけん Functional requirements စနစ်က ဘာလုပ်ရမလဲဆိုသည့် လိုအပ်ချက်များ
  • 非機能要件NFR ひきのうようけん Non-functional requirements အမြန်နှုန်း၊ လုံခြုံရေး၊ ရရှိနိုင်မှု စသည့် လုပ်ဆောင်ချက်မဟုတ်သော လိုအပ်ချက်များ
  • 業務フロー ぎょうむふろー Business flow လုပ်ငန်းဆောင်ရွက်ပုံ အဆင့်ဆင့်ကို ပြသည့် ပုံ
  • ユースケース ゆーすけーす Use case အသုံးပြုသူက စနစ်ကို ဘယ်လို အသုံးပြုမလဲဆိုသည့် ဖြစ်စဉ်
  • シーケンス図 しーけんすず Sequence diagram object များကြား ဆက်သွယ်မှု အစီအစဉ်ကို ပြသည့် ပုံ
  • クラス図 くらすず Class diagram class များနှင့် ၎င်းတို့ ဆက်စပ်ပုံကို ပြသည့် ပုံ
  • インターフェースI/F いんたーふぇーす Interface စနစ်နှစ်ခု သို့မဟုတ် module နှစ်ခုကြား ချိတ်ဆက်ပုံ သတ်မှတ်ချက်
  • 外部連携 がいぶれんけい External integration ပြင်ပစနစ်များနှင့် ဒေတာ အပြန်အလှန် ချိတ်ဆက်ခြင်း
  • バッチ処理 ばっちしょり Batch processing ဒေတာ အများအပြားကို သတ်မှတ်အချိန်တွင် စုပြီး လုပ်ဆောင်ခြင်း
  • オンライン処理 おんらいんしょり Online processing အသုံးပြုသူ လုပ်ဆောင်ချက်ကို ချက်ချင်း ပြန်လည်တုံ့ပြန်သည့် လုပ်ဆောင်မှု
  • 権限 けんげん Permission လုပ်ဆောင်ခွင့် သို့မဟုတ် ဝင်ရောက်ခွင့်
  • 認証 にんしょう Authentication အသုံးပြုသူ မည်သူဖြစ်ကြောင်း အတည်ပြုခြင်း
  • 認可 にんか Authorization အသုံးပြုသူအား ဘာလုပ်ခွင့်ရှိသလဲ ခွင့်ပြုခြင်း
  • 正規化 せいきか Normalization (DB) ဒေတာ ထပ်နေခြင်းမရှိအောင် table များကို ခွဲခြမ်းစီစဉ်ခြင်း
  • 主キーPK しゅきー Primary key table အတွင်း row တစ်ခုချင်းစီကို သီးသန့်ခွဲခြားသည့် key
  • 外部キーFK がいぶきー Foreign key အခြား table ၏ primary key ကို ရည်ညွှန်းသည့် key
  • インデックス いんでっくす Index (DB) ဒေတာ ရှာဖွေမှု မြန်စေရန် ဖန်တီးထားသော အညွှန်း
  • トランザクション とらんざくしょん Transaction အားလုံးအောင်မြင်မှ အတည်ပြုပြီး တစ်ခုခုမှားရင် အားလုံးပြန်ပယ်သည့် လုပ်ဆောင်မှု အစု
  • 排他制御 はいたせいぎょ Concurrency control လုပ်ငန်းစဉ်များက ဒေတာတစ်ခုတည်းကို တစ်ပြိုင်နက် ကိုင်တွယ်ရာတွင် ပဋိပက္ခမဖြစ်အောင် ထိန်းချုပ်ခြင်း
  • 採番 さいばん Number assignment ID သို့မဟုတ် နံပါတ်အသစ် ထုတ်ပေးခြင်း
  • マスタ ますた Master data ကုန်ပစ္စည်း၊ ဖောက်သည် စသည့် အခြေခံ ဒေတာ (မကြာခဏ မပြောင်းလဲ)
  • 入力チェック にゅうりょくちぇっく Input validation အသုံးပြုသူ ထည့်သွင်းသည့် ဒေတာ မှန်မမှန် စစ်ဆေးခြင်း
  • 仕様変更 しようへんこう Specification change မူလ သတ်မှတ်ချက်ကို ပြောင်းလဲခြင်း
  • 仕様確認 しようかくにん Specification check သတ်မှတ်ချက်ကို မေးမြန်းအတည်ပြုခြင်း
  • 前提条件 ぜんていじょうけん Precondition ကြိုတင်ပြည့်စုံရမည့် အခြေအနေ
  • 制約 せいやく Constraint ကန့်သတ်ချက်
  • 要望 ようぼう Request (from users) အသုံးပြုသူ သို့မဟုတ် ဖောက်သည်၏ လိုချင်ချက်
  • 帳票設計 ちょうひょうせっけい Report design လုပ်ငန်းသုံး ပုံစံ/report ၏ layout ကို ဒီဇိုင်းဆွဲခြင်း
  • テーブル てーぶる Table (DB) ဒေတာဘေ့စ်ရှိ row နှင့် column ဖြင့် ဖွဲ့စည်းထားသော ဇယား
  • カラム からむ Column (DB) table ၏ ကော်လံ (ဒေတာ item တစ်ခု)
  • レコード れこーど Record (row) table ၏ ဒေတာ row တစ်ကြောင်း
  • 件数 けんすう Number of records ဒေတာ အရေအတွက်
  • 集計 しゅうけい Aggregation ဒေတာများကို ပေါင်းခြင်း၊ ရေတွက်ခြင်း
  • 抽出 ちゅうしゅつ Extraction ဒေတာထဲမှ လိုအပ်သည်ကို ထုတ်ယူခြင်း
  • 重複 ちょうふく Duplication ထပ်နေခြင်း
  • データ不整合 でーたふせいごう Data inconsistency ဒေတာများကြား မကိုက်ညီခြင်း
  • 整合性 せいごうせい Consistency ကိုက်ညီမှု
  • 概要設計 がいようせっけい Outline design စနစ်၏ အကြမ်းဖျင်း ဒီဇိုင်း
  • 機能一覧 きのういちらん Function list စနစ်၏ လုပ်ဆောင်ချက်များ စာရင်း
  • 画面一覧 がめんいちらん Screen list စနစ်ရှိ screen များ စာရင်း
  • フローチャート ふろーちゃーと Flowchart လုပ်ငန်းစဉ် အဆင့်ဆင့်ကို ပုံဖြင့် ပြခြင်း
  • 状態遷移 じょうたいせんい State transition အခြေအနေတစ်ခုမှ အခြားတစ်ခုသို့ ပြောင်းလဲပုံ
  • ワイヤーフレーム わいやーふれーむ Wireframe screen ၏ layout ကို ရိုးရှင်းစွာ ဆွဲထားသော ပုံကြမ်း
  • プロトタイプ ぷろとたいぷ Prototype စမ်းသပ်ရန် ဖန်တီးထားသော နမူနာ
  • たたき台 たたきだい Rough draft (for discussion) ဆွေးနွေးရန် အခြေခံအဖြစ် ပြင်ဆင်ထားသော မူကြမ်း
  • 粒度 りゅうど Granularity အသေးစိတ် အဆင့်
  • 要件漏れ ようけんもれ Missed requirement လိုအပ်ချက်တစ်ခု ကျန်ခဲ့ခြင်း
  • 改版履歴 かいはんりれき Revision history စာတမ်း ပြင်ဆင်မှုမှတ်တမ်း
  • 版数 はんすう Version number (of a document) စာတမ်း၏ ဗားရှင်းနံပါတ်
  • 最新版 さいしんばん Latest version နောက်ဆုံးထွက် ဗားရှင်း
  • 差し替え さしかえ Replacement (of a file) ဖိုင် သို့မဟုတ် စာတမ်းကို အသစ်ဖြင့် အစားထိုးခြင်း
  • マイクロサービス まいくろさーびす Microservices စနစ်ကို သေးငယ်သော service လေးများအဖြစ် ခွဲပြီး တည်ဆောက်သည့်ပုံစံ
  • 拡張性 かくちょうせい Extensibility / scalability စနစ်၏ လုပ်ဆောင်ချက် သို့မဟုတ် ကိုင်တွယ်နိုင်စွမ်းကို နောက်ပိုင်း လွယ်ကူစွာ တိုးချဲ့နိုင်မှု
  • 疎結合 そけつごう Loose coupling အစိတ်အပိုင်းများ အချင်းချင်း မှီခိုမှု နည်းခြင်း
  • 密結合 みっけつごう Tight coupling အစိတ်အပိုင်းများ အချင်းချင်း မှီခိုမှု များခြင်း
  • 要求 ようきゅう Requirement (request) ဖောက်သည်က လိုချင်သည်ဟု တောင်းဆိုသော အရာ
  • 要件定義書 ようけんていぎしょ Requirements specification requirement များကို ရေးသားထားသော စာရွက်စာတမ်း
  • 基本設計書 きほんせっけいしょ Basic design document စနစ်၏ အခြေခံ ဒီဇိုင်းကို ရေးထားသော စာရွက်စာတမ်း
  • 詳細設計書 しょうさいせっけいしょ Detailed design document program ရေးရန်အတွက် အသေးစိတ် ဒီဇိုင်း စာရွက်စာတမ်း
  • 画面仕様書 がめんしようしょ Screen specification screen တစ်ခုချင်း၏ အသေးစိတ် လုပ်ဆောင်ချက်ကို ရေးထားသော စာ
  • API仕様書 えーぴーあいしようしょ API specification API ၏ request/response ပုံစံကို ရေးထားသော စာ
  • 処理フロー しょりふろー Process flow လုပ်ဆောင်ချက်များ၏ အစီအစဉ်ကို ပြသော ပုံ
  • データフロー でーたふろー Data flow data များ ဘယ်ကနေ ဘယ်ကို စီးဆင်းသည်ကို ပြခြင်း
  • システム構成図 しすてむこうせいず System configuration diagram စနစ်၏ server၊ network ဖွဲ့စည်းပုံ ပုံ
  • 論理設計 ろんりせっけい Logical design database ကို ယုတ္တိပိုင်း (အမျိုးအစား မပါ) ဒီဇိုင်းဆွဲခြင်း
  • 物理設計 ぶつりせっけい Physical design database ၏ table၊ type၊ index ကို တကယ် ဒီဇိုင်းဆွဲခြင်း
  • DB設計 でぃーびーせっけい Database design database ၏ table ဖွဲ့စည်းပုံကို ဒီဇိုင်းဆွဲခြင်း
  • テーブル設計 てーぶるせっけい Table design table ၏ column နှင့် key များကို ဒီဇိုင်းဆွဲခြင်း
  • 画面レイアウト がめんれいあうと Screen layout screen ပေါ်ရှိ အစိတ်အပိုင်းများ နေရာချထားပုံ
  • ユーザビリティ ゆーざびりてぃ Usability အသုံးပြုရ လွယ်ကူမှု
  • アクセシビリティ あくせしびりてぃ Accessibility မသန်စွမ်းသူ အပါအဝင် လူတိုင်း အသုံးပြုနိုင်မှု
  • 入力項目 にゅうりょくこうもく Input field (item) user ထည့်ရမည့် အချက်အလက် အကွက်
  • 出力 しゅつりょく Output ရလဒ် ထုတ်ပေးခြင်း
  • 入力 にゅうりょく Input အချက်အလက် ထည့်သွင်းခြင်း
  • 初期表示 しょきひょうじ Initial display screen ကို ပထမဆုံး ဖွင့်သည့်အခါ ပြသပုံ
  • 必須チェック ひっすちぇっく Required-field check မဖြည့်မနေရ အကွက် ဖြည့်မဖြည့် စစ်ခြင်း
