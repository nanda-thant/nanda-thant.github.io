  • 競技プログラミング きょうぎぷろぐらみんぐ Competitive programming အချိန်ကန့်သတ်ချက်အတွင်း algorithm ပုစ္ဆာများကို program ရေး၍ ဖြေရှင်းသော ပြိုင်ပွဲ
  • 問題文 もんだいぶん Problem statement ပုစ္ဆာ၏ အကြောင်းအရာနှင့် လိုအပ်ချက်များကို ရေးထားသော စာ
  • 計算 けいさん Calculation ကိန်းဂဏန်းများကို တွက်ချက်ခြင်း
  • 計算量 けいさんりょう Time complexity input အရွယ်အစား ကြီးလာသည်နှင့်အမျှ တွက်ချက်ရသော အကြိမ်ရေ မည်မျှ တိုးလာသည်ကို ပြသော တိုင်းတာချက် (O(N) စသည်)
  • 実行時間 じっこうじかん Running time program တစ်ခု run ရန် ကြာသော အချိန်
  • 時間制限 じかんせいげん Time limit program ပြီးဆုံးရမည့် အများဆုံး အချိန် (ဥပမာ ၂ စက္ကန့်)
  • メモリ制限 めもりせいげん Memory limit program သုံးနိုင်သော memory ပမာဏ အများဆုံး
  • 入力例 にゅうりょくれい Sample input ပုစ္ဆာတွင် ပေးထားသော နမူနာ input
  • 出力例 しゅつりょくれい Sample output input နမူနာအတွက် မှန်ကန်သော output နမူနာ
  • 標準入力 ひょうじゅんにゅうりょく Standard input program က keyboard သို့မဟုတ် ဖိုင်မှ ဖတ်သော ပုံမှန် input
  • 標準出力 ひょうじゅんしゅつりょく Standard output program ၏ ရလဒ်ကို ထုတ်ပေးသော ပုံမှန်နေရာ
  • 空白区切り くうはくくぎり Space-separated တန်ဖိုးများကြားတွင် space ခြား၍ ရေးထားခြင်း
  • 提出 ていしゅつ Submission ရေးထားသော code ကို စစ်ဆေးရန် ပေးပို့ခြင်း
  • 正解AC せいかい Correct answer မှန်ကန်သော အဖြေ၊ စစ်ဆေးမှု အားလုံး အောင်ခြင်း
  • 不正解WA ふせいかい Wrong answer output မှားယွင်းခြင်း
  • 実行時エラーRE じっこうじえらー Runtime error program run နေစဉ် ဖြစ်ပေါ်သော error (array အပြင်ဘက် access စသည်)
  • 時間超過TLE じかんちょうか Time limit exceeded အချိန်ကန့်သတ်ချက်အတွင်း program မပြီးခြင်း
  • 判定 はんてい Judge တင်သွင်းထားသော အဖြေမှန်မမှန်ကို စစ်ဆေးဆုံးဖြတ်ခြင်း (judge)
  • 解説 かいせつ Editorial ပုစ္ဆာ၏ ဖြေရှင်းနည်းကို ရှင်းပြထားသော စာ
  • 解答 かいとう Answer ပုစ္ဆာ၏ အဖြေ (code)
  • 全探索 ぜんたんさく Brute force ဖြစ်နိုင်ခြေ အားလုံးကို တစ်ခုချင်း စမ်းကြည့်သော နည်း
  • ビット全探索 びっとぜんたんさく Bit brute force bit ကို သုံး၍ အစုခွဲ အားလုံးကို စမ်းကြည့်သော နည်း
  • 累積和 るいせきわ Prefix sum ရှေ့ဆုံးမှ နေရာတစ်ခုအထိ ပေါင်းလဒ်ကို ကြိုတွက်ထားခြင်း၊ အပိုင်းအခြား ပေါင်းလဒ်ကို O(1) ဖြင့် ရနိုင်သည်
  • 区間 くかん Interval အစနှင့် အဆုံး သတ်မှတ်ထားသော အပိုင်း (L မှ R အထိ)
  • 二分探索 にぶんたんさく Binary search စီထားသော data ကို တစ်ဝက်စီ ခွဲ၍ ရှာသော နည်း၊ O(log N)
  • 線形探索 せんけいたんさく Linear search ရှေ့မှ နောက်သို့ တစ်ခုချင်း ရှာသော နည်း၊ O(N)
  • 探索 たんさく Search လိုချင်သော အရာကို ရှာဖွေခြင်း (algorithm)
  • 貪欲法 どんよくほう Greedy algorithm အဆင့်တိုင်းတွင် ထိုအချိန်၌ အကောင်းဆုံးကို ရွေးသွားသော နည်း
  • 動的計画法DP どうてきけいかくほう Dynamic programming ပုစ္ဆာကို အငယ်လေးများ ခွဲ၍ ရလဒ်များကို သိမ်းကာ ပြန်သုံးသော နည်း
  • 漸化式 ぜんかしき Recurrence relation ရှေ့တန်ဖိုးများမှ နောက်တန်ဖိုးကို တွက်သော ပုံသေနည်း (dp[i] = dp[i-1] + dp[i-2] စသည်)
  • メモ化 めもか Memoization တွက်ပြီးသော ရလဒ်ကို မှတ်ထား၍ ထပ်မတွက်ခြင်း
  • 尺取り法 しゃくとりほう Two pointers အစနှင့် အဆုံး pointer နှစ်ခုကို ရွှေ့၍ အပိုင်းအခြားကို ရှာသော နည်း
  • 座標圧縮 ざひょうあっしゅく Coordinate compression တန်ဖိုးကြီးများကို အစီအစဉ်အလိုက် 0, 1, 2 … ဖြင့် အစားထိုးခြင်း
  • 添字 そえじ Index array ထဲရှိ element ၏ နေရာနံပါတ် (0 မှ စသည်)
  • 二次元配列 にじげんはいれつ 2D array အတန်းနှင့် အတိုင် ပါသော array (grid)
  • 部分文字列 ぶぶんもじれつ Substring string အတွင်းမှ ဆက်တိုက် အပိုင်းတစ်ခု
  • 部分和 ぶぶんわ Subset sum element အချို့ကို ရွေး၍ ပေါင်းလဒ် တစ်ခု ရနိုင်မနိုင် ပုစ္ဆာ
  • 最大値 さいだいち Maximum အကြီးဆုံး တန်ဖိုး
  • 最小値 さいしょうち Minimum အငယ်ဆုံး တန်ဖိုး
  • 昇順 しょうじゅん Ascending order ငယ်စဉ်ကြီးလိုက် အစီအစဉ်
  • 降順 こうじゅん Descending order ကြီးစဉ်ငယ်လိုက် အစီအစဉ်
  • 素数 そすう Prime number 1 နှင့် ၎င်းကိုယ်တိုင်သာ စားလို့ပြတ်သော ၂ နှင့်အထက် ကိန်း (သုဒ္ဓကိန်း)
  • 約数 やくすう Divisor ကိန်းတစ်ခုကို စားလို့ပြတ်သော ကိန်း
  • 最大公約数 さいだいこうやくすう Greatest common divisor ကိန်းနှစ်ခုလုံးကို စားလို့ပြတ်သော အကြီးဆုံးကိန်း (အကြီးဆုံး ဘုံဆခွဲကိန်း)
  • 最小公倍数 さいしょうこうばいすう Least common multiple ကိန်းနှစ်ခုလုံး၏ ဆတိုးကိန်းဖြစ်သော အငယ်ဆုံးကိန်း
  • 余り あまり Remainder စားပြီးနောက် ကျန်သော ကိန်း
  • 剰余 じょうよ Modulo စားကြွင်း (余り ၏ သင်္ချာဆန်သော အခေါ်)
  • 偶数 ぐうすう Even number 2 ဖြင့် စားလို့ပြတ်သော ကိန်း (စုံကိန်း)
  • 奇数 きすう Odd number 2 ဖြင့် စားလို့မပြတ်သော ကိန်း (မကိန်း)
  • 桁 けた Digit ဂဏန်း၏ နေရာ (ခု၊ ဆယ်၊ ရာ …) သို့မဟုတ် ဂဏန်းလုံးရေ
  • 絶対値 ぜったいち Absolute value အနုတ်လက္ခဏာ ဖယ်ထားသော တန်ဖိုး (|x|)
  • 平方根 へいほうこん Square root နှစ်ထပ်ကိန်းရင်း (√)
  • 累乗 るいじょう Power ကိန်းတစ်ခုကို ၎င်းကိုယ်တိုင်ဖြင့် အကြိမ်ကြိမ် မြှောက်ခြင်း (aⁿ)
  • 階乗 かいじょう Factorial 1 မှ n အထိ ကိန်းအားလုံးကို မြှောက်ခြင်း (n!)
  • 順列 じゅんれつ Permutation အရာများကို အစီအစဉ် အမျိုးမျိုး စီခြင်း
  • 組合せ くみあわせ Combination အစီအစဉ် မစဉ်းစားဘဲ ရွေးချယ်ခြင်း
  • 集合 しゅうごう Set ထပ်နေသော အရာ မပါသည့် အစု
  • グラフ ぐらふ Graph vertex (頂点) များနှင့် ၎င်းတို့ကို ဆက်သော edge (辺) များ ပါသော ဖွဲ့စည်းပုံ
  • 頂点 ちょうてん Vertex graph ၏ အမှတ် (node)
  • 辺 へん Edge graph တွင် vertex နှစ်ခုကို ဆက်သော မျဉ်း
  • 重み おもみ Weight edge တစ်ခုကို ဖြတ်ရန် ကုန်ကျသော တန်ဖိုး (အကွာအဝေး၊ ကုန်ကျစရိတ်)
  • 木 き Tree cycle မပါဘဲ vertex အားလုံး ဆက်နေသော graph
  • 二分木 にぶんぎ Binary tree node တစ်ခုစီတွင် child အများဆုံး နှစ်ခု ရှိသော tree
  • 閉路 へいろ Cycle vertex တစ်ခုမှ ထွက်၍ ထိုနေရာသို့ ပြန်ရောက်သော လမ်းကြောင်း
  • 連結成分 れんけつせいぶん Connected component graph အတွင်း အချင်းချင်း သွားလာနိုင်သော vertex အုပ်စု
  • 隣接リスト りんせつりすと Adjacency list vertex တစ်ခုချင်းစီမှ ဆက်နေသော vertex များ၏ စာရင်းဖြင့် graph ကို သိမ်းခြင်း
  • 深さ優先探索DFS ふかさゆうせんたんさく Depth-first search တစ်လမ်းကြောင်းကို အဆုံးထိ အရင်သွား၍ ရှာသော နည်း
  • 幅優先探索BFS はばゆうせんたんさく Breadth-first search အနီးဆုံးမှ စ၍ အလွှာလိုက် ရှာသော နည်း
  • 最短経路 さいたんけいろ Shortest path နေရာနှစ်ခုကြား အတိုဆုံး (ကုန်ကျစရိတ် အနည်းဆုံး) လမ်းကြောင်း
  • ダイクストラ法 だいくすとらほう Dijkstra's algorithm weight အနုတ်မပါသော graph တွင် အတိုဆုံးလမ်းကြောင်းကို ရှာသော နည်း
  • キュー きゅー Queue အရင်ဝင်သည်က အရင်ထွက်သော (FIFO) data ဖွဲ့စည်းပုံ
  • スタック すたっく Stack နောက်ဆုံးဝင်သည်က အရင်ထွက်သော (LIFO) data ဖွဲ့စည်းပုံ
  • 優先度付きキュー ゆうせんどつききゅー Priority queue အသေးဆုံး (သို့မဟုတ် အကြီးဆုံး) ကို အရင်ထုတ်ပေးသော queue
  • Union-Find ゆにおんふぁいんど Union-Find အုပ်စုများကို ပေါင်းခြင်းနှင့် တူညီသော အုပ်စု ဟုတ်မဟုတ် စစ်ခြင်းကို မြန်မြန် လုပ်ပေးသော data ဖွဲ့စည်းပုံ
  • オーバーフロー おーばーふろー Overflow ကိန်းသည် type ၏ သိမ်းနိုင်သော အကြီးဆုံးတန်ဖိုးကို ကျော်သွားခြင်း
  • 誤差 ごさ Error (tolerance) တွက်ချက်ရာတွင် ဖြစ်ပေါ်သော တန်ဖိုး အနည်းငယ် ကွာခြားမှု
  • 番兵 ばんぺい Sentinel loop ၏ အဆုံးကို စစ်ရန် လွယ်စေရန် ထည့်ထားသော အထူးတန်ဖိုး
