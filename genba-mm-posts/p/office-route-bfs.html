会議室までの最短ルート

The shortest way to the meeting room

2026-11-14 · ふつう 幅優先探索BFSグリッド

問題

オフィスのフロアは縦 H マス、横 W マスのマス目で表されます。各マスは次のどれかです。

  • .：通れる床
  • #：壁や机で通れない
  • S：自分の席（通れる）
  • G：会議室（通れる）

1 歩で上下左右のとなりのマスに動けます。自分の席から会議室まで最短で何歩かを出力してください。たどり着けないときは -1 を出力してください。

問題 (en)

An office floor is a grid of H rows and W columns. Each cell is one of:

  • .: floor you can walk on
  • #: a wall or desk you cannot pass
  • S: your seat (walkable)
  • G: the meeting room (walkable)

One step moves you to the next cell up, down, left or right. Print the fewest steps from your seat to the meeting room, or -1 if you cannot get there.

問題 (my)

ရုံးခန်း၏ ကြမ်းပြင်ကို ဒေါင်လိုက် H ကွက်၊ အလျားလိုက် W ကွက် ရှိသော grid ဖြင့် ဖော်ပြသည်။ အကွက်တစ်ကွက်ချင်းစီသည် အောက်ပါတို့ထဲမှ တစ်ခု ဖြစ်သည်။

  • .: လမ်းလျှောက်နိုင်သော ကြမ်းပြင်
  • #: နံရံ သို့မဟုတ် စားပွဲ (ဖြတ်၍ မရ)
  • S: ကျွန်တော့် ထိုင်ခုံ (လျှောက်နိုင်သည်)
  • G: အစည်းအဝေးခန်း (လျှောက်နိုင်သည်)

တစ်လှမ်းဖြင့် အပေါ်၊ အောက်၊ ဘယ်၊ ညာ ဘေးကပ်အကွက်သို့ ရွှေ့နိုင်သည်။ ထိုင်ခုံမှ အစည်းအဝေးခန်းအထိ အနည်းဆုံး ခြေလှမ်းအရေအတွက်ကို ထုတ်ပြပါ။ မရောက်နိုင်လျှင် -1 ကို ထုတ်ပြပါ။

制約

  • 1 ≤ H, W ≤ 1000
  • 各行は . # S G だけからなる長さ W の文字列
  • S と G はちょうど 1 つずつある

入力

H W
1 行目の文字列
⋮
H 行目の文字列

出力

最短の歩数、または -1 を 1 行で出力してください。

入力例 1

4 5
S..#.
.#...
.#.#.
...#G

出力例 1

7

右に 2 歩、下に 1 歩、右に 2 歩、下に 2 歩で 7 歩です。

入力例 2

2 3
S#G
.#.

出力例 2

-1

ヒント

自分の席から「1 歩で行けるマス」「2 歩で行けるマス」…と、近い順に広げていくとどうなるでしょうか。一度たどり着いたマスは、もう一度調べる必要はありません。

ヒント (en)

What if you spread out from your seat in order of distance: the cells one step away, then two steps away, and so on? A cell you have already reached never needs to be looked at again.

ヒント (my)

ထိုင်ခုံမှစ၍ "တစ်လှမ်းဖြင့် ရောက်နိုင်သော အကွက်များ"၊ "နှစ်လှမ်းဖြင့် ရောက်နိုင်သော အကွက်များ" ... ဟု နီးသည့်အစဉ်အတိုင်း ချဲ့သွားလျှင် မည်သို့ ဖြစ်မည်နည်း။ တစ်ကြိမ် ရောက်ပြီးသော အကွက်ကို ထပ်စစ်ရန် မလိုပါ။

解説

幅優先探索（BFS）を使います。キューに S を入れ、取り出したマスの上下左右のうち、通れてまだ距離が決まっていないマスに「今の距離 + 1」を書いてキューに入れます。

キューは先に入れたものから出てくるので、マスは S から近い順に調べられます。そのため、最初に書いた距離がそのマスの最短距離になります。各マスは 1 回しかキューに入らないので O(HW) です。

距離の配列を -1 で埋めておけば、「まだ来ていない」の印と、たどり着けないときの答えを兼ねられます。

解説 (en)

Use breadth-first search (BFS). Put S in a queue. For each cell taken out, look at its four neighbours; every walkable one without a distance yet gets "this distance + 1" and goes into the queue.

A queue hands cells back in the order they went in, so cells are visited nearest first, and the first distance written for a cell is its shortest one. Each cell enters the queue once: O(HW).

Filling the distance array with -1 marks "not reached yet" and is also the answer when G cannot be reached.

解説 (my)

BFS (幅優先探索) ကို သုံးပါ။ S ကို queue ထဲ ထည့်ပါ။ queue မှ ထုတ်ယူသော အကွက်၏ အပေါ်၊ အောက်၊ ဘယ်၊ ညာ အကွက်များထဲမှ လျှောက်နိုင်ပြီး အကွာအဝေး မသတ်မှတ်ရသေးသော အကွက်တွင် "လက်ရှိ အကွာအဝေး + 1" ကို ရေးပြီး queue ထဲ ထည့်ပါ။

queue သည် အရင်ထည့်သည့်အရာကို အရင်ထုတ်ပေးသောကြောင့် အကွက်များကို S နှင့် နီးသည့်အစဉ်အတိုင်း စစ်သည်။ ထို့ကြောင့် အကွက်တစ်ခုတွင် ပထမဆုံး ရေးသော အကွာအဝေးသည် အတိုဆုံး အကွာအဝေး ဖြစ်သည်။ အကွက်တိုင်း queue ထဲသို့ တစ်ကြိမ်သာ ဝင်သောကြောင့် O(HW) ဖြစ်သည်။

အကွာအဝေး array ကို -1 ဖြင့် ဖြည့်ထားလျှင် "မရောက်ရသေး" ဟူသော အမှတ်အသားနှင့် မရောက်နိုင်သည့်အခါ၏ အဖြေ နှစ်ခုစလုံး ဖြစ်သည်။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int h = Integer.parseInt(st.nextToken());
        int w = Integer.parseInt(st.nextToken());

        char[][] grid = new char[h][];
        int start = 0, goal = 0;   // cell number = row * w + column
        for (int r = 0; r < h; r++) {
            grid[r] = br.readLine().trim().toCharArray();
            for (int c = 0; c < w; c++) {
                if (grid[r][c] == 'S') start = r * w + c;
                if (grid[r][c] == 'G') goal = r * w + c;
            }
        }

        int[] dist = new int[h * w];
        Arrays.fill(dist, -1);   // -1 = not reached yet
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        dist[start] = 0;
        queue.add(start);
        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};
        while (!queue.isEmpty()) {
            int cell = queue.poll();
            int r = cell / w, c = cell % w;
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr < 0 || nr >= h || nc < 0 || nc >= w || grid[nr][nc] == '#') continue;
                int next = nr * w + nc;
                if (dist[next] != -1) continue;
                dist[next] = dist[cell] + 1;
                queue.add(next);
            }
        }
        System.out.println(dist[goal]);
    }
}
