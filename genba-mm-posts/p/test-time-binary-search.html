時間内に終わるテスト

Tests that finish in time

2026-11-08 · ふつう 二分探索ソート

問題

あるシステムには N 個の自動テストがあり、i 番目のテストの実行時間は Tᵢ 秒です。

Q 個の質問に答えてください。j 番目の質問では整数 Xⱼ が与えられるので、実行時間が Xⱼ 秒以下のテストがいくつあるかを出力してください。

問題 (en)

A system has N automated tests, and test i takes Tᵢ seconds to run.

Answer Q questions. Question j gives an integer Xⱼ: print how many tests take Xⱼ seconds or less.

問題 (my)

စနစ်တစ်ခုတွင် automated test N ခု ရှိပြီး i ခုမြောက် test ၏ run ချိန်သည် Tᵢ စက္ကန့် ဖြစ်သည်။

မေးခွန်း Q ခုကို ဖြေပါ။ j ခုမြောက် မေးခွန်းတွင် ကိန်းပြည့် Xⱼ ကို ပေးထားသောကြောင့် run ချိန် Xⱼ စက္ကန့် နှင့်အောက် ဖြစ်သော test မည်မျှ ရှိသည်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, Q ≤ 2×10⁵
  • 1 ≤ Tᵢ, Xⱼ ≤ 10⁹
  • 入力はすべて整数

入力

N Q
T_1 T_2 … T_N
X_1
⋮
X_Q

出力

Q 行出力してください。j 行目には j 番目の質問の答えを出力してください。

入力例 1

5 3
30 10 20 20 50
20
5
100

出力例 1

3
0
5

20 秒以下のテストは 10, 20, 20 秒の 3 個です。

ヒント

T を小さい順に並べ替えると、「X 秒以下」のテストは配列の前のほうにまとまります。その境目を速く見つける方法は？

ヒント (en)

Once T is sorted, the tests that take X seconds or less are all at the front of the array. How can you find where they end quickly?

ヒント (my)

T ကို ငယ်စဉ်ကြီးလိုက် စီလိုက်လျှင် X စက္ကန့် နှင့်အောက် စမ်းသပ်မှုများသည် array ၏ ရှေ့ပိုင်းတွင် စုနေမည်။ ထိုနယ်နိမိတ်ကို မြန်မြန် ရှာနိုင်မည့် နည်းလမ်း ရှိပါသလား။

解説

まず T をソートします（O(N log N)）。すると答えは「X より大きい最初の位置」と同じです。この位置は二分探索で O(log N) で見つかります。

全体の計算量は O((N + Q) log N) です。質問ごとに全部を数えると O(NQ) で、最大 4×10¹⁰ 回になり間に合いません。

二分探索では「条件を満たす範囲」と「満たさない範囲」の境目を lo と hi ではさんでいき、ずれやすい +1 / -1 に注意しましょう。下のコードでは t[lo] <= x が常に成り立ち、t[hi] > x が常に成り立つように書いています。

解説 (en)

Sort T first (O(N log N)). The answer is then the index of the first value greater than X, which binary search finds in O(log N). In total that is O((N + Q) log N), while counting every test for every question would be O(NQ), up to 4×10¹⁰ steps.

Keep an invariant to avoid off-by-one bugs: in the code below t[lo] <= x and t[hi] > x always hold (with imaginary values at −1 and N).

解説 (my)

ပထမဦးစွာ T ကို sort လုပ်ပါ (O(N log N))။ ထို့နောက် အဖြေသည် X ထက် ကြီးသော ပထမဆုံး နေရာ ဖြစ်ပြီး binary search (二分探索) ဖြင့် O(log N) အတွင်း ရှာနိုင်သည်။ စုစုပေါင်း O((N + Q) log N) ဖြစ်သည်။

Off-by-one bug ကို ရှောင်ရန် invariant ကို ထိန်းထားပါ: အောက်ပါ code တွင် t[lo] <= x နှင့် t[hi] > x သည် အမြဲမှန်ရမည် (−1 နှင့် N နေရာများကို စိတ်ကူးယဉ်နယ်နိမိတ်အဖြစ် သတ်မှတ်ထားသည်)။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int q = Integer.parseInt(st.nextToken());

        int[] t = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) t[i] = Integer.parseInt(st.nextToken());
        Arrays.sort(t);

        StringBuilder out = new StringBuilder();
        for (int j = 0; j < q; j++) {
            int x = Integer.parseInt(br.readLine().trim());
            // Invariant: t[lo] <= x (lo = -1 means "before the array"), t[hi] > x (hi = n means "after it").
            int lo = -1, hi = n;
            while (hi - lo > 1) {
                int mid = (lo + hi) >>> 1;
                if (t[mid] <= x) lo = mid; else hi = mid;
            }
            out.append(hi).append('\n');   // hi = number of values <= x
        }
        System.out.print(out);
    }
}
