入門7 研修の評価 A・B・C

Basics 7 · Grade A, B or C

2026-11-08 · やさしい 入門条件分岐

問題

研修の最終テストで S 点を取りました。評価は次のとおりです。

  • 80 点以上：A
  • 60 点以上 80 点未満：B
  • 60 点未満：C

評価を出力してください。

問題 (en)

You scored S points on the final test of your training. The grade is:

  • 80 or more: A
  • 60 or more and under 80: B
  • under 60: C

Print the grade.

問題 (my)

သင်တန်း၏ နောက်ဆုံး စာမေးပွဲတွင် S မှတ် ရခဲ့သည်။ အဆင့် သတ်မှတ်ချက်မှာ အောက်ပါအတိုင်း ဖြစ်သည်။

  • 80 မှတ်နှင့်အထက်: A
  • 60 မှတ်နှင့်အထက်၊ 80 မှတ်အောက်: B
  • 60 မှတ်အောက်: C

အဆင့်ကို ထုတ်ပြပါ။

制約

  • 0 ≤ S ≤ 100
  • S は整数

入力

S

出力

A、B、C のどれかを出力してください。

入力例 1

85

出力例 1

A

入力例 2

80

出力例 2

A

入力例 3

60

出力例 3

B

入力例 4

12

出力例 4

C

ヒント

3 つ以上に分けるときは if … else if … else を使います。条件を上から順に調べて、最初に当てはまったものだけが実行されます。

ヒント (en)

For three or more cases, use if … else if … else. The conditions are checked from the top, and only the first one that matches runs.

ヒント (my)

အခြေအနေ သုံးမျိုးနှင့်အထက် ခွဲရန် if … else if … else ကို သုံးပါ။ အခြေအနေများကို အပေါ်မှ အစဉ်လိုက် စစ်ပြီး ပထမဆုံး ကိုက်ညီသည့် အပိုင်းသာ အလုပ်လုပ်သည်။

解説

if (s >= 80) {
    System.out.println("A");
} else if (s >= 60) {
    System.out.println("B");
} else {
    System.out.println("C");
}

2 つ目の条件は s >= 60 だけで十分です。そこに来た時点で「80 点未満」だとわかっているからです。

順番を逆にして s >= 60 を先に書くと、85 点も B になってしまいます。厳しい条件から先に書きましょう。

解説 (en)

The second condition only needs s >= 60: if the program gets there, the score is already known to be under 80.

If you check s >= 60 first, 85 would also print B. Put the strictest condition first.

解説 (my)

ဒုတိယ အခြေအနေတွင် s >= 60 တစ်ခုတည်း လုံလောက်သည်။ ထိုနေရာသို့ ရောက်လာလျှင် ၈၀ အောက် ဖြစ်ကြောင်း သိပြီးသား ဖြစ်သောကြောင့်ပါ။

s >= 60 ကို အရင်စစ်လျှင် ၈၅ မှတ်လည်း B ဖြစ်သွားပါမည်။ အတင်းကျပ်ဆုံး အခြေအနေကို အရင်ရေးပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int s = sc.nextInt();
        if (s >= 80) {
            System.out.println("A");
        } else if (s >= 60) {
            System.out.println("B");
        } else {
            System.out.println("C");
        }
    }
}
