入門6 勤務時間は何分？

Basics 6 · How many minutes did you work?

2026-11-08 · やさしい 入門文字列計算

問題

出勤時刻 S と退勤時刻 T が HH:MM の形で与えられます。S から T まで何分あるかを出力してください。

問題 (en)

You are given the time you started work, S, and the time you left, T, in the form HH:MM. Print how many minutes there are from S to T.

問題 (my)

အလုပ်စချိန် S နှင့် အလုပ်ဆင်းချိန် T ကို HH:MM ပုံစံဖြင့် ပေးထားသည်။ S မှ T အထိ မိနစ် မည်မျှ ရှိသည်ကို ထုတ်ပြပါ။

制約

  • S と T は 00:00 から 23:59 までの時刻
  • S は T と同じか、T より前

入力

S T

出力

S から T までの分数を出力してください。

入力例 1

09:00 18:30

出力例 1

570

9 時間 30 分 = 570 分です。

入力例 2

08:45 17:15

出力例 2

510

ヒント

時刻をそのまま引き算することはできません。どちらも「0 時 0 分から何分か」に直してから引きましょう。"09:00".split(":") で "09" と "00" に分けられます。

ヒント (en)

You cannot subtract times as they are. Turn each into "minutes since 00:00" first, then subtract. "09:00".split(":") splits it into "09" and "00".

ヒント (my)

အချိန်ကို ဒီအတိုင်း နုတ်၍ မရပါ။ နှစ်ခုလုံးကို «00:00 မှ စ၍ မိနစ်ပေါင်း» အဖြစ် အရင်ပြောင်းပြီးမှ နုတ်ပါ။ "09:00".split(":") ဖြင့် "09" နှင့် "00" ဟု ခွဲနိုင်သည်။

解説

HH:MM を分に直すと HH × 60 + MM です。09:00 は 540 分、18:30 は 1110 分なので、答えは 1110 − 540 = 570 です。

Integer.parseInt("09") は先頭の 0 があっても 9 を返します。

同じ処理を 2 回使うので、メソッドにまとめると読みやすくなります。

解説 (en)

HH:MM in minutes is HH × 60 + MM. 09:00 is 540 and 18:30 is 1110, so the answer is 1110 − 540 = 570.

Integer.parseInt("09") returns 9; the leading zero is fine.

The conversion is needed twice, so a small method keeps the code readable.

解説 (my)

HH:MM ကို မိနစ်ပြောင်းလျှင် HH × 60 + MM ဖြစ်သည်။ 09:00 သည် ၅၄၀ မိနစ်၊ 18:30 သည် ၁၁၁၀ မိနစ် ဖြစ်သဖြင့် အဖြေမှာ 1110 − 540 = 570 ဖြစ်သည်။

Integer.parseInt("09") သည် ရှေ့က 0 ရှိသော်လည်း 9 ကို ပြန်ပေးသည်။ တူညီသော တွက်ချက်မှုကို နှစ်ကြိမ် သုံးရသဖြင့် method တစ်ခုအဖြစ် ခွဲရေးလျှင် ဖတ်ရလွယ်ပါသည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    static int toMinutes(String time) {
        String[] parts = time.split(":");
        int h = Integer.parseInt(parts[0]);
        int m = Integer.parseInt(parts[1]);
        return h * 60 + m;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        String t = sc.next();
        System.out.println(toMinutes(t) - toMinutes(s));
    }
}
