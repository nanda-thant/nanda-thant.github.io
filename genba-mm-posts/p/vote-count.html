ステップアップ1 アンケートの集計

Step up 1 · Counting survey votes

2026-11-08 · ふつう ステップアップ配列計算量

問題

社内アンケートで、M 個の案（1 番から M 番）に N 人が 1 票ずつ投票しました。i 番目の人は Vᵢ 番の案に投票しました。

各案の得票数を、1 番から順に空白区切りで出力してください。

問題 (en)

In an in-house survey, N people each cast one vote for one of M proposals (numbered 1 to M). Person i voted for proposal Vᵢ.

Print the number of votes for each proposal, starting from proposal 1, separated by spaces.

問題 (my)

ကုမ္ပဏီတွင်း စစ်တမ်းတွင် အဆိုပြုချက် M ခု (1 မှ M အထိ) အတွက် လူ N ယောက်က တစ်ယောက်လျှင် တစ်မဲ ပေးခဲ့သည်။ i ယောက်မြောက်သည် Vᵢ နံပါတ် အဆိုပြုချက်ကို မဲပေးခဲ့သည်။

အဆိုပြုချက် တစ်ခုချင်းစီ ရရှိသော မဲအရေအတွက်ကို 1 မှ စ၍ space ခြားပြီး ထုတ်ပြပါ။

制約

  • 1 ≤ N, M ≤ 2×10⁵
  • 1 ≤ Vᵢ ≤ M
  • 入力はすべて整数

入力

N M
V_1 V_2 … V_N

出力

M 個の得票数を空白区切りで 1 行に出力してください。

入力例 1

6 3
1 3 3 2 3 1

出力例 1

2 1 3

入力例 2

2 4
4 4

出力例 2

0 0 0 2

ヒント

案ごとに「全員の票を見て数える」と、M × N = 4×10¹⁰ 回の計算になり間に合いません。票を 1 回読むだけで数えられる方法を考えましょう。

ヒント (en)

Counting each option by scanning every vote takes M × N = 4×10¹⁰ steps, which is too slow. Find a way to count while reading the votes only once.

ヒント (my)

အစီအစဉ်တစ်ခုချင်းအတွက် မဲအားလုံးကို ပြန်ကြည့်ပြီး ရေတွက်လျှင် M × N = 4×10¹⁰ ကြိမ် တွက်ရပြီး အချိန်မမီပါ။ မဲများကို တစ်ကြိမ်တည်း ဖတ်ရင်း ရေတွက်နိုင်သည့် နည်းကို စဉ်းစားပါ။

解説

長さ M + 1 の配列 cnt を用意し、票 v を読むたびに cnt[v]++ します。案の番号をそのまま配列の添字に使うのがポイントです。計算量は O(N + M) です。

計算量の目安：Java は 1 秒に約 10⁸〜10⁹ 回の簡単な計算ができます。制約の最大値を入れて、回数がそれより十分小さいか確かめましょう。

出力が多いので、System.out.println を何十万回も呼ぶと遅くなります。StringBuilder にまとめてから 1 回で出力します。

解説 (en)

Make an array cnt of length M + 1 and do cnt[v]++ for each vote v. The trick is to use the option number directly as the array index. This is O(N + M).

A rule of thumb for time complexity: Java does about 10⁸–10⁹ simple steps per second. Put the largest values from the constraints into your step count and check it stays well below that.

The output is long, so calling System.out.println hundreds of thousands of times is slow. Collect it in a StringBuilder and print once.

解説 (my)

အရှည် M + 1 ရှိသော array cnt ကို ပြင်ပြီး မဲ v ကို ဖတ်တိုင်း cnt[v]++ လုပ်ပါ။ အစီအစဉ် နံပါတ်ကို array index အဖြစ် တိုက်ရိုက်သုံးခြင်းသည် အဓိကဖြစ်သည်။ O(N + M) ဖြစ်သည်။

計算量 (time complexity) အတွက် မှတ်ချက်: Java သည် တစ်စက္ကန့်လျှင် ရိုးရှင်းသော တွက်ချက်မှု 10⁸–10⁹ ခန့် လုပ်နိုင်သည်။ ကန့်သတ်ချက်၏ အမြင့်ဆုံးတန်ဖိုးဖြင့် တွက်ကြည့်ပါ။

Output အလွန်ရှည်နိုင်သဖြင့် System.out.println ကို သိန်းနှင့်ချီ ခေါ်ခြင်းက နှေးသည်။ StringBuilder ထဲ စုထားပြီး တစ်ကြိမ်တည်း ထုတ်ပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[] cnt = new int[m + 1];        // cnt[v] = votes for option v
        for (int i = 0; i < n; i++) {
            cnt[sc.nextInt()]++;
        }
        StringBuilder sb = new StringBuilder();
        for (int v = 1; v <= m; v++) {
            if (v > 1) sb.append(' ');
            sb.append(cnt[v]);
        }
        System.out.println(sb);
    }
}
