入門11 キャメルケースをスネークケースに

Basics 11 · camelCase to snake_case

2026-11-08 · やさしい 入門文字列

問題

Java の変数名 S（キャメルケース）を、データベースの列名（スネークケース）に変換してください。

  • 大文字の前に _ を入れ、その大文字を小文字にします。
  • 例：userName → user_name

問題 (en)

Convert the Java variable name S (camelCase) into a database column name (snake_case).

  • Put _ in front of each capital letter and make that letter lowercase.
  • Example: userName → user_name

問題 (my)

Java variable အမည် S (camel case) ကို database column အမည် (snake case) သို့ ပြောင်းပါ။

  • စာလုံးကြီး၏ ရှေ့တွင် _ ထည့်ပြီး ထိုစာလုံးကြီးကို စာလုံးသေးသို့ ပြောင်းပါ။
  • ဥပမာ: userName → user_name

制約

  • S は英字のみからなる 1 文字以上 50 文字以下の文字列
  • S の最初の文字は小文字

入力

S

出力

変換した文字列を出力してください。

入力例 1

userName

出力例 1

user_name

入力例 2

getHttpResponseCode

出力例 2

get_http_response_code

入力例 3

id

出力例 3

id

ヒント

文字列を 1 文字ずつ見ていきます。s.charAt(i) で i 番目の文字（char）が取れます。大文字かどうかは Character.isUpperCase(c) で調べられます。結果は StringBuilder に足していきましょう。

ヒント (en)

Look at the string one character at a time: s.charAt(i) gives the i-th char, and Character.isUpperCase(c) tells you whether it is a capital. Build the result in a StringBuilder.

ヒント (my)

String ကို စာလုံးတစ်လုံးချင်း ကြည့်ပါ။ s.charAt(i) ဖြင့် i ကြိမ်မြောက် char ကို ရနိုင်ပြီး Character.isUpperCase(c) ဖြင့် စာလုံးကြီး ဟုတ်မဟုတ် စစ်နိုင်သည်။ ရလဒ်ကို StringBuilder ထဲ ဆက်ထည့်ပါ။

解説

  • StringBuilder の append で 1 文字ずつ足し、最後に toString() で文字列にします。
  • 大文字なら _ を足してから Character.toLowerCase(c) を足します。
  • String を += でつなげても動きますが、毎回新しい文字列が作られます。長い文字列を作るときは StringBuilder を使う習慣をつけましょう。

for (char c : s.toCharArray()) と書くと、添字なしで 1 文字ずつ取り出せます。

解説 (en)

  • append each character to a StringBuilder, then call toString() at the end.
  • For a capital, append _ and then Character.toLowerCase(c).
  • Joining with String += also works, but it creates a new string every time. Get used to StringBuilder for building long strings.

for (char c : s.toCharArray()) loops over the characters without an index.

解説 (my)

  • စာလုံးတစ်လုံးချင်းကို StringBuilder ထဲ append လုပ်ပြီး နောက်ဆုံးတွင် toString() ဖြင့် String ပြောင်းပါ။
  • စာလုံးကြီး ဖြစ်လျှင် _ ကို အရင်ထည့်ပြီး Character.toLowerCase(c) ကို ထည့်ပါ။
  • String += ဖြင့် ဆက်လည်း ရသော်လည်း အကြိမ်တိုင်း String အသစ် ဖန်တီးသဖြင့် ရှည်သော string များအတွက် StringBuilder ကို သုံးပါ။

for (char c : s.toCharArray()) ကို သုံးလျှင် index မလိုဘဲ စာလုံးတစ်လုံးချင်းကို ပတ်ကြည့်နိုင်သည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isUpperCase(c)) {
                sb.append('_').append(Character.toLowerCase(c));
            } else {
                sb.append(c);
            }
        }
        System.out.println(sb.toString());
    }
}
