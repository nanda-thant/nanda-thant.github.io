ステップアップ5 おつりの硬貨を少なく

Step up 5 · Change with the fewest coins

2026-11-08 · ふつう ステップアップ貪欲法

問題

社内の自動販売機のプログラムを作っています。おつり N 円を、500 円、100 円、50 円、10 円、5 円、1 円の硬貨で払います。硬貨の枚数を最も少なくしたときの枚数を出力してください。

問題 (en)

You are writing the program for the office vending machine. It pays N yen of change in 500, 100, 50, 10, 5 and 1 yen coins. Print the number of coins when as few coins as possible are used.

問題 (my)

ရုံးရှိ အလိုအလျောက် ရောင်းစက် (自動販売機) ၏ program ကို ရေးနေသည်။ ပြန်အမ်းငွေ N ယန်းကို 500၊ 100၊ 50၊ 10၊ 5၊ 1 ယန်း အကြွေစေ့များဖြင့် ပေးသည်။ အကြွေစေ့ အရေအတွက် အနည်းဆုံး ဖြစ်အောင် ပေးသောအခါ၏ အရေအတွက်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 10⁹
  • N は整数

入力

N

出力

硬貨の最少枚数を出力してください。

入力例 1

768

出力例 1

9

500 円 1 枚、100 円 2 枚、50 円 1 枚、10 円 1 枚、5 円 1 枚、1 円 3 枚です。

入力例 2

1000

出力例 2

2

ヒント

大きい硬貨から、使えるだけ使っていきましょう。「使えるだけ」は割り算で一度に求められます。

ヒント (en)

Start with the largest coin and use as many as you can. "As many as you can" is one division.

ヒント (my)

အကြီးဆုံး အကြွေစေ့မှ စ၍ သုံးနိုင်သမျှ သုံးပါ။ «သုံးနိုင်သမျှ» ကို စားခြင်းတစ်ကြိမ်ဖြင့် ရှာနိုင်သည်။

解説

硬貨 c について、n / c 枚使い、残りは n % c 円です。これを大きい順にくり返します。

このように「その場で一番よさそうなものを選び続ける」方法を貪欲法（greedy）と呼びます。

ただし、貪欲法はいつも正しいとは限りません。たとえば硬貨が 1 円、3 円、4 円で 6 円を払うとき、貪欲法では 4 + 1 + 1 の 3 枚ですが、3 + 3 の 2 枚が正解です。日本の硬貨では貪欲法で正しく求められますが、貪欲法を使うときは「本当に正しいか」を考える習慣をつけましょう。

解説 (en)

For coin c, use n / c coins and continue with n % c yen, from the largest coin down.

Always taking the choice that looks best right now is called a greedy algorithm (貪欲法).

Greedy is not always right. With coins of 1, 3 and 4 yen, greedy pays 6 yen as 4 + 1 + 1 (3 coins), but 3 + 3 (2 coins) is better. It works for Japanese coins, but always ask whether greedy is really correct before using it.

解説 (my)

အကြွေစေ့ c အတွက် n / c စေ့ သုံးပြီး ကျန်သည့် n % c ယန်းဖြင့် ဆက်လုပ်ပါ။ အကြီးမှ အငယ်သို့ ထပ်ခါထပ်ခါ လုပ်ပါ။

ယခုအချိန်တွင် အကောင်းဆုံးထင်ရသည်ကို ဆက်တိုက်ရွေးသည့်နည်းကို 貪欲法 (greedy) ဟုခေါ်သည်။

Greedy သည် အမြဲမှန်သည် မဟုတ်ပါ။ ဥပမာ 1၊ 3၊ 4 ယန်း အကြွေစေ့ဖြင့် 6 ယန်း ပေးလျှင် greedy က 4 + 1 + 1 (၃ စေ့) ဟု ဖြေသော်လည်း 3 + 3 (၂ စေ့) က ပိုကောင်းသည်။ ဂျပန်အကြွေစေ့များတွင်မူ မှန်ပါသည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] coins = {500, 100, 50, 10, 5, 1};
        int count = 0;
        for (int c : coins) {
            count += n / c;
            n %= c;
        }
        System.out.println(count);
    }
}
