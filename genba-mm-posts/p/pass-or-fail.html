入門2 確認テストの合否

Basics 2 · Pass or fail

2026-11-08 · やさしい 入門条件分岐

問題

新人研修の確認テストで S 点を取りました。60 点以上なら合格です。

合格なら PASS、そうでなければ FAIL と出力してください。

問題 (en)

You scored S points on the check test of your new-hire training. 60 points or more is a pass.

Print PASS if you passed, otherwise FAIL.

問題 (my)

ဝန်ထမ်းသစ် သင်တန်း၏ စစ်ဆေးမှု စာမေးပွဲတွင် S မှတ် ရခဲ့သည်။ 60 မှတ်နှင့်အထက် ဖြစ်လျှင် အောင်သည်။

အောင်လျှင် PASS၊ မအောင်လျှင် FAIL ဟု ထုတ်ပြပါ။

制約

  • 0 ≤ S ≤ 100
  • S は整数

入力

S

出力

PASS または FAIL を出力してください。

入力例 1

75

出力例 1

PASS

入力例 2

60

出力例 2

PASS

ちょうど 60 点も合格です。

入力例 3

59

出力例 3

FAIL

ヒント

if 文を使います。「60 点以上」は S >= 60 です。S > 60 にすると、60 点のときに間違えます。

ヒント (en)

Use an if statement. "60 or more" is S >= 60. With S > 60, a score of exactly 60 gives the wrong answer.

ヒント (my)

if statement ကို သုံးပါ။ «၆၀ နှင့်အထက်» ဆိုသည်မှာ S >= 60 ဖြစ်သည်။ S > 60 ဟု ရေးလျှင် ၆၀ မှတ်တိတိတွင် အဖြေမှားပါမည်။

解説

条件で処理を分けるには if (条件) { … } else { … } を使います。

このような「境界」（ちょうど 60 点）は、競技プログラミングでも実務の単体試験でも、バグが一番出やすい場所です。入力例 2 のように、境界の値で必ず確認しましょう。

解説 (en)

To choose between two actions, use if (condition) { … } else { … }.

Boundaries like "exactly 60" are where bugs hide most often, in contests and in unit tests at work alike. Always try the boundary value, as sample 2 does.

解説 (my)

အခြေအနေအလိုက် ခွဲလုပ်ရန် if (condition) { … } else { … } ကို သုံးပါ။

«၆၀ တိတိ» ကဲ့သို့ နယ်နိမိတ်တန်ဖိုးများတွင် bug အများဆုံး ပေါ်တတ်ပါသည်။ ပြိုင်ပွဲတွင်ရော လုပ်ငန်းခွင် unit test တွင်ပါ နယ်နိမိတ်တန်ဖိုးကို အမြဲ စစ်ပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int s = sc.nextInt();
        if (s >= 60) {
            System.out.println("PASS");
        } else {
            System.out.println("FAIL");
        }
    }
}
