入門10 1 年間のリクエスト数

Basics 10 · Requests in a year

2026-11-08 · やさしい 入門計算オーバーフロー

問題

あるサーバーには 1 秒に A 件のリクエストが来ます。S 秒間に来るリクエストの数を出力してください。

問題 (en)

A server receives A requests per second. Print the number of requests it receives in S seconds.

問題 (my)

server တစ်ခုသို့ တစ်စက္ကန့်လျှင် request A ခု ရောက်လာသည်။ S စက္ကန့်အတွင်း ရောက်လာသော request အရေအတွက်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ A ≤ 10⁶
  • 1 ≤ S ≤ 31536000（1 年の秒数）
  • 入力はすべて整数

入力

A S

出力

リクエストの数を出力してください。

入力例 1

1000 86400

出力例 1

86400000

1 日（86400 秒）の場合です。

入力例 2

50000 31536000

出力例 2

1576800000000

ヒント

int に入るのは約 21 億（2147483647）までです。入力例 2 の答えは約 1.5 兆なので、long を使いましょう。

ヒント (en)

An int holds values up to about 2.1 billion (2147483647). Sample 2's answer is about 1.5 trillion, so use long.

ヒント (my)

int ထဲတွင် သန်း ၂၁၀၀ ခန့် (2147483647) အထိသာ ဆံ့သည်။ ဥပမာ ၂ ၏ အဖြေသည် 1.5 trillion ခန့် ဖြစ်သဖြင့် long ကို သုံးပါ။

解説

int で a * s を計算すると、範囲を超えた分が回り込んで（オーバーフロー）、エラーも出ずに間違った数が出力されます。入力例 2 では 547002368 という、まったく違う数になります。

注意：long ans = a * s; と書いても、a と s が int なら、掛け算は int のまま行われてからの代入なので間違えます。最初から long a = sc.nextLong(); と読むか、(long) a * s と書きます。

答えがどこまで大きくなるか、制約の最大値を掛け算して確かめる習慣をつけましょう：10⁶ × 3.2×10⁷ ≒ 3.2×10¹³。

解説 (en)

With int, a * s silently wraps around (overflow): no error, just a wrong number. Sample 2 would print 547002368, a completely different number.

Careful: long ans = a * s; is still wrong if a and s are ints, because the multiplication happens in int before the assignment. Read them with sc.nextLong(), or write (long) a * s.

Make it a habit to multiply the largest values in the constraints: 10⁶ × 3.2×10⁷ ≈ 3.2×10¹³.

解説 (my)

int ဖြင့် a * s ကို တွက်လျှင် အပိုင်းအခြားကို ကျော်သွားပြီး (overflow) error မပြဘဲ ဂဏန်းမှားကို ထုတ်ပါမည်။ ဥပမာ ၂ တွင် 547002368 ဟူသော လုံးဝမဆိုင်သည့် ဂဏန်း ထွက်ပါမည်။

သတိ: a နှင့် s သည် int ဖြစ်နေလျှင် long ans = a * s; ဟု ရေးသော်လည်း မြှောက်ခြင်းကို int ဖြင့် အရင်တွက်ပြီးမှ ထည့်သဖြင့် မှားပါမည်။ sc.nextLong() ဖြင့် ဖတ်ပါ သို့မဟုတ် (long) a * s ဟု ရေးပါ။

ကန့်သတ်ချက်တွင် အများဆုံးဖြစ်နိုင်သော တန်ဖိုးများကို မြှောက်ပြီး အဖြေ၏ အမြင့်ဆုံးပမာဏကို စစ်ဆေးသည့် အကျင့် ပြုလုပ်ထားပါ: 10⁶ × 3.2×10⁷ ≈ 3.2×10¹³။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long a = sc.nextLong();
        long s = sc.nextLong();
        System.out.println(a * s);
    }
}
