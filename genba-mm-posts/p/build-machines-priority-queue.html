ビルドマシンの割り当て

Sharing the build machines

2026-11-14 · ふつう 優先度付きキューシミュレーション

問題

CI には M 台のビルドマシンがあり、時刻 0 にはすべて空いています。ビルド待ちのジョブが N 個あり、i 番目のジョブには Dᵢ 分かかります。

ジョブは番号の順に、そのとき一番早く空くマシンで実行されます（空いた瞬間に次のジョブが始まります）。すべてのジョブが終わる時刻を出力してください。

問題 (en)

The CI has M build machines, all free at time 0. N jobs are waiting, and job i takes Dᵢ minutes.

The jobs start in order, each on the machine that becomes free first (the next job starts the moment a machine is free). Print the time at which all the jobs have finished.

問題 (my)

CI တွင် build စက် M လုံး ရှိပြီး အချိန် 0 တွင် အားလုံး အားနေသည်။ build စောင့်နေသော job N ခု ရှိပြီး i ခုမြောက် job သည် Dᵢ မိနစ် ကြာသည်။

job များကို နံပါတ်အစဉ်အတိုင်း ထိုအချိန်တွင် အစောဆုံး အားမည့် စက်ပေါ်တွင် run သည် (စက် အားသည့် ချက်ချင်း နောက် job စသည်)။ job အားလုံး ပြီးဆုံးသည့် အချိန်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, M ≤ 2×10⁵
  • 1 ≤ Dᵢ ≤ 10⁹
  • 入力はすべて整数

入力

N M
D_1 D_2 … D_N

出力

すべてのジョブが終わる時刻を 1 行で出力してください。

入力例 1

5 2
4 2 3 1 5

出力例 1

10

1 番目はマシン A で 0〜4 分、2 番目はマシン B で 0〜2 分、3 番目は B で 2〜5 分、4 番目は A で 4〜5 分、5 番目は 5〜10 分に動きます。

入力例 2

1 3
7

出力例 2

7

入力例 3

3 1
1 2 3

出力例 3

6

ヒント

ジョブごとに M 台すべてを見て一番早く空くマシンを探すと O(NM) です。「一番小さい値を取り出す」「値を入れる」の 2 つが速くできる入れ物を使いましょう。

ヒント (en)

Looking at all M machines for every job is O(NM). Use a container that is fast at two things: taking out the smallest value and putting a value in.

ヒント (my)

job တစ်ခုချင်းစီအတွက် စက် M လုံးလုံးကို ကြည့်ပြီး အစောဆုံး အားမည့်စက်ကို ရှာလျှင် O(NM) ဖြစ်သည်။ "အငယ်ဆုံးတန်ဖိုးကို ထုတ်ယူခြင်း" နှင့် "တန်ဖိုး ထည့်ခြင်း" နှစ်ခုကို မြန်မြန် လုပ်နိုင်သော container ကို သုံးပါ။

解説

各マシンが「次に空く時刻」を優先度付きキュー（Java では PriorityQueue）に入れておきます。最初は 0 が M 個です。

ジョブごとに、一番小さい時刻 free を取り出し、free + D を入れ直します。これがそのジョブの終わる時刻なので、その最大値が答えです。取り出しと追加はどちらも O(log M) なので、全体で O(N log M + M) です。

時刻は最大で 2×10⁵ × 10⁹ になるので long を使います。

解説 (en)

Keep the time at which each machine is next free in a priority queue (PriorityQueue in Java). At the start it holds M zeros.

For each job, take out the smallest time free and put free + D back. That is when this job ends, and the answer is the largest of those times. Both operations are O(log M), so the total is O(N log M + M).

Times can reach 2×10⁵ × 10⁹, so use long.

解説 (my)

စက်တစ်လုံးချင်းစီ၏ "နောက်တစ်ကြိမ် အားမည့်အချိန်" ကို priority queue (優先度付きキュー) (Java တွင် PriorityQueue) ထဲ ထည့်ထားပါ။ အစတွင် 0 ကို M ခု ထည့်ထားသည်။

job တစ်ခုချင်းစီအတွက် အငယ်ဆုံးအချိန် free ကို ထုတ်ယူပြီး free + D ကို ပြန်ထည့်ပါ။ ၎င်းသည် ထို job ပြီးမည့်အချိန် ဖြစ်ပြီး ထိုအချိန်များ၏ အကြီးဆုံးတန်ဖိုးသည် အဖြေ ဖြစ်သည်။ ထုတ်ယူခြင်းနှင့် ထည့်ခြင်း နှစ်ခုစလုံး O(log M) ဖြစ်သောကြောင့် စုစုပေါင်း O(N log M + M) ဖြစ်သည်။

အချိန်သည် 2×10⁵ × 10⁹ အထိ ရောက်နိုင်သောကြောင့် long ကို သုံးပါ။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        PriorityQueue<Long> freeAt = new PriorityQueue<>();   // smallest time first
        for (int i = 0; i < m; i++) freeAt.add(0L);

        long last = 0;
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            long d = Long.parseLong(st.nextToken());
            long end = freeAt.poll() + d;   // the machine that is free first
            freeAt.add(end);
            last = Math.max(last, end);
        }
        System.out.println(last);
    }
}
