入門3 今週の作業時間

Basics 3 · Hours worked this week

2026-11-08 · やさしい 入門ループ

問題

あなたは今週 N 日働きました。i 日目の作業時間は Hᵢ 時間です。今週の作業時間の合計を出力してください。

問題 (en)

You worked N days this week. On day i you worked Hᵢ hours. Print your total working hours for the week.

問題 (my)

သင်သည် ဤအပတ်တွင် N ရက် အလုပ်လုပ်ခဲ့သည်။ i ရက်မြောက်နေ့တွင် Hᵢ နာရီ အလုပ်လုပ်ခဲ့သည်။ ဤအပတ်၏ အလုပ်ချိန် စုစုပေါင်းကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 100
  • 0 ≤ Hᵢ ≤ 24
  • 入力はすべて整数

入力

N
H_1 H_2 … H_N

出力

合計の作業時間を出力してください。

入力例 1

5
8 9 8 10 7

出力例 1

42

入力例 2

1
0

出力例 2

0

ヒント

数がいくつあるかは N で決まるので、for ループで N 回読みます。合計を入れる変数を 0 から始めて、読むたびに足していきましょう。

ヒント (en)

How many numbers there are depends on N, so read them with a for loop that runs N times. Start a total at 0 and add each number as you read it.

ヒント (my)

ဂဏန်း ဘယ်နှစ်လုံးရှိလဲဆိုတာ N ပေါ် မူတည်သဖြင့် N ကြိမ် ပတ်သော for loop ဖြင့် ဖတ်ပါ။ စုစုပေါင်းအတွက် variable ကို 0 မှ စပြီး ဖတ်တိုင်း ပေါင်းထည့်ပါ။

解説

int sum = 0;
for (int i = 0; i < n; i++) {
    sum += sc.nextInt();
}

sum += x は sum = sum + x と同じ意味です。

Scanner は空白と改行を区別しないので、数が 1 行に並んでいても、1 行に 1 つずつでも同じコードで読めます。

解説 (en)

Keep a running total in a loop. sum += x means sum = sum + x.

Scanner treats spaces and line breaks the same, so this code works whether the numbers are on one line or one per line.

解説 (my)

Loop ထဲတွင် စုစုပေါင်းကို တဖြည်းဖြည်း ပေါင်းပါ။ sum += x သည် sum = sum + x နှင့် အဓိပ္ပာယ်တူသည်။

Scanner သည် space နှင့် စာကြောင်းအသစ်ကို ခွဲမခြားသဖြင့် ဂဏန်းများ တစ်ကြောင်းတည်းတွင် ရှိစေ၊ တစ်ကြောင်းစီ ရှိစေ ဤ code ဖြင့်ပင် ဖတ်နိုင်ပါသည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += sc.nextInt();
        }
        System.out.println(sum);
    }
}
