ステップアップ9 chmod の数字を読む

Step up 9 · Reading chmod numbers

2026-11-08 · ふつう ステップアップビット演算文字列

問題

Linux のファイル権限は chmod 754 のように 3 桁の数字で書けます。各桁は左から所有者、グループ、その他の人の権限で、次の数を足したものです。

  • 4：読み取り r
  • 2：書き込み w
  • 1：実行 x

3 桁の数字 P が与えられるので、ls -l と同じ 9 文字の形（許可されていない所は -）で出力してください。

問題 (en)

Linux file permissions can be written as three digits, as in chmod 754. From the left, the digits are the permissions of the owner, the group and everyone else, each the sum of:

  • 4: read r
  • 2: write w
  • 1: execute x

Given the three-digit number P, print it in the 9-character form used by ls -l (- where a permission is not given).

問題 (my)

Linux ၏ file permission ကို chmod 754 ကဲ့သို့ ဂဏန်း ၃ လုံးဖြင့် ရေးနိုင်သည်။ ဘယ်မှ စ၍ ဂဏန်းတစ်လုံးချင်းသည် owner၊ group နှင့် အခြားသူများ၏ permission ဖြစ်ပြီး အောက်ပါ ဂဏန်းများကို ပေါင်းထားခြင်း ဖြစ်သည်။

  • 4: ဖတ်ခွင့် r
  • 2: ရေးခွင့် w
  • 1: run ခွင့် x

ဂဏန်း ၃ လုံးပါ P ကို ပေးထားသောကြောင့် ls -l နှင့် တူသော စာလုံး 9 လုံး ပုံစံဖြင့် ထုတ်ပြပါ (ခွင့်မပြုထားသော နေရာတွင် -)။

制約

  • P は 3 文字の文字列で、各文字は 0 から 7

入力

P

出力

9 文字の権限を出力してください。

入力例 1

754

出力例 1

rwxr-xr--

7 = 4 + 2 + 1、5 = 4 + 1、4 = 4 です。

入力例 2

644

出力例 2

rw-r--r--

入力例 3

700

出力例 3

rwx------

ヒント

各桁を 2 進数で書くと、7 は 111、5 は 101、4 は 100 です。3 つのビットがそれぞれ r、w、x に対応しています。ビットが立っているかは & で調べられます。

ヒント (en)

In binary, 7 is 111, 5 is 101 and 4 is 100: the three bits are r, w and x. Test a bit with &.

ヒント (my)

ဂဏန်းတစ်လုံးချင်းကို binary ဖြင့် ရေးလျှင် 7 သည် 111၊ 5 သည် 101၊ 4 သည် 100 ဖြစ်သည်။ Bit သုံးခုသည် r၊ w၊ x အသီးသီးနှင့် ကိုက်ညီသည်။ Bit ရှိမရှိကို & ဖြင့် စစ်နိုင်သည်။

解説

文字 '7' を数の 7 にするには c - '0' とします（文字コードの差です）。

d & 4 は d の「4 のビット」が立っていれば 4、立っていなければ 0 になります。なので (d & 4) != 0 なら r、そうでなければ - です。w（2）と x（1）も同じです。

このように 1 つの数の各ビットを ON / OFF のフラグとして使う方法は、権限、設定、ゲームの状態など、実務でもよく出てきます。

解説 (en)

Turn the character '7' into the number 7 with c - '0' (the difference of character codes).

d & 4 is 4 if d has the "4" bit set and 0 if not, so (d & 4) != 0 means r, otherwise -. Do the same for w (2) and x (1).

Using each bit of a number as an on/off flag is common in real code: permissions, settings, feature flags.

解説 (my)

စာလုံး '7' ကို ဂဏန်း 7 အဖြစ် ပြောင်းရန် c - '0' ဟု ရေးပါ။

d & 4 သည် d တွင် «4 bit» ရှိလျှင် 4၊ မရှိလျှင် 0 ဖြစ်သည်။ ထို့ကြောင့် (d & 4) != 0 ဆိုလျှင် r၊ မဟုတ်လျှင် - ဖြစ်သည်။ w (2) နှင့် x (1) ကိုလည်း ထိုနည်းအတိုင်း စစ်ပါ။

ဂဏန်းတစ်ခု၏ bit တစ်ခုချင်းကို ON/OFF flag အဖြစ် သုံးခြင်းသည် လုပ်ငန်းခွင်တွင်လည်း အသုံးများသည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String p = sc.next();
        StringBuilder sb = new StringBuilder();
        for (char c : p.toCharArray()) {
            int d = c - '0';
            sb.append((d & 4) != 0 ? 'r' : '-');
            sb.append((d & 2) != 0 ? 'w' : '-');
            sb.append((d & 1) != 0 ? 'x' : '-');
        }
        System.out.println(sb);
    }
}
