ステップアップ8 定例会議が重なる日

Step up 8 · When the regular meetings fall on the same day

2026-11-08 · ふつう ステップアップ数学最大公約数

問題

チーム A の定例会議は A 日ごと、チーム B の定例会議は B 日ごとに開かれます。今日は両方の会議がありました。

次に両方の会議が同じ日になるのは何日後か出力してください。

問題 (en)

Team A's regular meeting is held every A days and team B's every B days. Both meetings were held today.

Print how many days from now both meetings will next fall on the same day.

問題 (my)

အဖွဲ့ A ၏ ပုံမှန် အစည်းအဝေးကို A ရက်တစ်ကြိမ်၊ အဖွဲ့ B ၏ ပုံမှန် အစည်းအဝေးကို B ရက်တစ်ကြိမ် ကျင်းပသည်။ ယနေ့ အစည်းအဝေး နှစ်ခုစလုံး ရှိခဲ့သည်။

နောက်တစ်ကြိမ် အစည်းအဝေး နှစ်ခု တစ်နေ့တည်း ကျမည့်နေ့သည် ယနေ့မှ ရက်မည်မျှ အကြာ ဖြစ်သည်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ A, B ≤ 10⁹
  • 入力はすべて整数

入力

A B

出力

何日後かを出力してください。

入力例 1

4 6

出力例 1

12

入力例 2

7 7

出力例 2

7

入力例 3

1000000000 999999999

出力例 3

999999999000000000

ヒント

答えは A と B の最小公倍数です。1 日ずつ調べると、入力例 3 では 10¹⁸ 日近く調べることになります。最小公倍数は最大公約数を使うと一瞬で求められます。

ヒント (en)

The answer is the least common multiple of A and B. Checking day by day would take nearly 10¹⁸ steps for sample 3. The LCM comes instantly from the greatest common divisor.

ヒント (my)

အဖြေသည် A နှင့် B ၏ အငယ်ဆုံး ဘုံဆတိုးကိန်း (LCM) ဖြစ်သည်။ တစ်ရက်ချင်း စစ်လျှင် ဥပမာ ၃ တွင် 10¹⁸ ရက်နီးပါး စစ်ရမည်။ LCM ကို အကြီးဆုံး ဘုံဆခွဲကိန်း (GCD) ဖြင့် ချက်ချင်း ရှာနိုင်သည်။

解説

ユークリッドの互除法で最大公約数（GCD）を求めます。

static long gcd(long a, long b) {
    return b == 0 ? a : gcd(b, a % b);
}

「a と b の GCD は、b と a % b の GCD に等しい」ことをくり返し使います。数が毎回大きく減るので、10⁹ でも 50 回もかかりません。

最小公倍数は a / gcd(a, b) * b です。a * b / gcd の順に計算すると、途中の a × b が 10¹⁸ になり、さらに大きい値では long でもあふれることがあります。先に割ってから掛けるのが安全です。

解説 (en)

Find the greatest common divisor (GCD) with the Euclidean algorithm: the GCD of a and b equals the GCD of b and a % b. The numbers shrink fast, so even 10⁹ takes fewer than 50 steps.

The LCM is a / gcd(a, b) * b. Computing a * b / gcd makes the intermediate a × b reach 10¹⁸, which can overflow even a long for bigger inputs. Divide first, then multiply.

解説 (my)

GCD ကို Euclid ၏ algorithm ဖြင့် ရှာပါ: a နှင့် b ၏ GCD သည် b နှင့် a % b ၏ GCD နှင့် တူညီသည်။ ဂဏန်းများ မြန်မြန် ငယ်သွားသဖြင့် 10⁹ ဖြစ်သော်လည်း ၅၀ ကြိမ်ပင် မကြာပါ။

LCM သည် a / gcd(a, b) * b ဖြစ်သည်။ a * b / gcd ဟု တွက်လျှင် ကြားတန်ဖိုး ကြီးလွန်းပြီး overflow ဖြစ်နိုင်သည်။ အရင်စားပြီးမှ မြှောက်ပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    static long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long a = sc.nextLong();
        long b = sc.nextLong();
        System.out.println(a / gcd(a, b) * b);
    }
}
