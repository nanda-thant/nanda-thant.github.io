ステップアップ4 ポイントの高いタスクを K 個

Step up 4 · The K tasks with the most points

2026-11-08 · ふつう ステップアップソート

問題

スプリントの候補に N 個のタスクがあり、i 番目のタスクの価値は Pᵢ ポイントです。今回は K 個だけ選べます。選んだタスクの価値の合計の最大値を出力してください。

問題 (en)

There are N candidate tasks for the sprint, and task i is worth Pᵢ points. This time you can choose only K of them. Print the largest total value of the tasks you choose.

問題 (my)

sprint အတွက် ရွေးချယ်နိုင်သော task N ခု ရှိပြီး i ခုမြောက် task ၏ တန်ဖိုးသည် Pᵢ point ဖြစ်သည်။ ဤတစ်ကြိမ်တွင် K ခုသာ ရွေးနိုင်သည်။ ရွေးထားသော task များ၏ တန်ဖိုး စုစုပေါင်း အများဆုံးကို ထုတ်ပြပါ။

制約

  • 1 ≤ K ≤ N ≤ 2×10⁵
  • 1 ≤ Pᵢ ≤ 10⁹
  • 入力はすべて整数

入力

N K
P_1 P_2 … P_N

出力

合計の最大値を出力してください。

入力例 1

5 2
3 9 1 7 5

出力例 1

16

9 と 7 を選びます。

入力例 2

3 3
1 2 3

出力例 2

6

ヒント

大きい順に K 個取れば最大です。並べ替えは自分で書かずに Arrays.sort を使いましょう。合計がどこまで大きくなるかも確認してください。

ヒント (en)

Taking the K largest gives the maximum. Do not write your own sort: use Arrays.sort. Also check how large the total can get.

ヒント (my)

အကြီးဆုံး K ခုကို ယူလျှင် အများဆုံး ရသည်။ Sort ကို ကိုယ်တိုင်မရေးဘဲ Arrays.sort ကို သုံးပါ။ စုစုပေါင်း ဘယ်လောက်အထိ ကြီးနိုင်သလဲလည်း စစ်ပါ။

解説

Arrays.sort(p) で小さい順に並べ、後ろから K 個を足します。ソートは O(N log N) です。

合計は最大 2×10⁵ × 10⁹ = 2×10¹⁴ なので long を使います。

大きい順に並べたいときは Integer[] にして Arrays.sort(a, Collections.reverseOrder()) とする方法もありますが、int[] を小さい順に並べて後ろから使う方が速く、簡単です。

自分でバブルソートなどを書くと O(N²) になり、N = 2×10⁵ では間に合いません。

解説 (en)

Sort ascending with Arrays.sort(p) and add the last K values. Sorting is O(N log N).

The total can reach 2×10⁵ × 10⁹ = 2×10¹⁴, so use long.

To sort in descending order you could use Integer[] with Collections.reverseOrder(), but sorting an int[] ascending and reading from the end is faster and simpler.

A hand-written bubble sort is O(N²) and too slow for N = 2×10⁵.

解説 (my)

Arrays.sort(p) ဖြင့် ငယ်စဉ်ကြီးလိုက် စီပြီး နောက်ဆုံး K ခုကို ပေါင်းပါ။ Sort သည် O(N log N) ဖြစ်သည်။

စုစုပေါင်းသည် 2×10¹⁴ အထိ ကြီးနိုင်သဖြင့် long ကို သုံးပါ။

Bubble sort ကဲ့သို့ ကိုယ်တိုင်ရေးလျှင် O(N²) ဖြစ်ပြီး N = 2×10⁵ တွင် အချိန်မမီပါ။

Integer[] ကို Collections.reverseOrder() ဖြင့် ကြီးစဉ်ငယ်လိုက် စီနိုင်သော်လည်း int[] ကို ငယ်စဉ်ကြီးလိုက် စီပြီး နောက်မှ ပြန်ဖတ်ခြင်းက ပိုမြန်၊ ပိုရိုးရှင်းသည်။

解答 (Java)

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        int[] p = new int[n];
        for (int i = 0; i < n; i++) {
            p[i] = sc.nextInt();
        }
        Arrays.sort(p);
        long sum = 0;
        for (int i = n - k; i < n; i++) {
            sum += p[i];
        }
        System.out.println(sum);
    }
}
