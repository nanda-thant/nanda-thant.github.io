入門1 残業時間の合計

Basics 1 · Total overtime

2026-11-08 · やさしい 入門入出力

問題

今月、あなたは前半に A 時間、後半に B 時間の残業をしました。今月の残業時間の合計を出力してください。

問題 (en)

This month you did A hours of overtime in the first half and B hours in the second half. Print your total overtime for the month.

問題 (my)

ဤလတွင် သင်သည် လ၏ ပထမပိုင်းတွင် A နာရီ၊ ဒုတိယပိုင်းတွင် B နာရီ အချိန်ပို (overtime) လုပ်ခဲ့သည်။ ဤလ၏ အချိန်ပို စုစုပေါင်းကို ထုတ်ပြပါ။

制約

  • 0 ≤ A, B ≤ 100
  • 入力はすべて整数

入力

A B

出力

合計の残業時間を 1 行で出力してください。

入力例 1

12 8

出力例 1

20

入力例 2

0 0

出力例 2

0

ヒント

これは「入力を読んで、計算して、出力する」練習です。Java では Scanner を使うと数字を簡単に読めます。sc.nextInt() を呼ぶたびに、整数が 1 つ読まれます。

ヒント (en)

This problem practises the basic pattern: read the input, calculate, print. In Java, Scanner reads numbers easily: every call to sc.nextInt() reads one integer.

ヒント (my)

ဒီပုစ္ဆာက «input ဖတ်၊ တွက်၊ output ထုတ်» ဆိုတဲ့ အခြေခံပုံစံကို လေ့ကျင့်ဖို့ပါ။ Java မှာ Scanner ကို သုံးရင် ဂဏန်းတွေကို လွယ်လွယ်ဖတ်နိုင်ပါတယ်။ sc.nextInt() ကို တစ်ခါခေါ်တိုင်း ကိန်းပြည့်တစ်လုံး ဖတ်ပါတယ်။

解説

  1. Scanner sc = new Scanner(System.in); で入力を読む準備をします。
  2. int a = sc.nextInt(); と int b = sc.nextInt(); で 2 つの数を読みます。
  3. System.out.println(a + b); で合計を出力します。

多くのジャッジ（AtCoder、paiza など）では、クラス名を Main にする必要があります。

注意：System.out.println("合計: " + a + b); と書くと、文字列の連結になって 合計: 128 と出力されてしまいます。計算は先に括弧で囲みましょう：("合計: " + (a + b))。

解説 (en)

  1. Scanner sc = new Scanner(System.in); gets ready to read the input.
  2. sc.nextInt() twice reads the two numbers.
  3. System.out.println(a + b); prints the total.

Most judges (AtCoder, paiza and others) require the class to be named Main.

Watch out: System.out.println("Total: " + a + b); joins strings and prints Total: 128. Put the calculation in brackets first: ("Total: " + (a + b)).

解説 (my)

  1. Scanner sc = new Scanner(System.in); ဖြင့် input ဖတ်ရန် ပြင်ဆင်ပါ။
  2. sc.nextInt() ကို နှစ်ကြိမ်ခေါ်ပြီး ဂဏန်းနှစ်လုံးကို ဖတ်ပါ။
  3. System.out.println(a + b); ဖြင့် စုစုပေါင်းကို ထုတ်ပါ။

Judge အများစု (AtCoder၊ paiza စသည်) တွင် class အမည်ကို Main ဟု ပေးရပါမည်။

သတိ: "Total: " + a + b ဟု ရေးလျှင် စာသားအဖြစ် ဆက်သွားပြီး Total: 128 ထွက်ပါမည်။ တွက်ချက်မှုကို ကွင်းထဲ အရင်ထည့်ပါ: ("Total: " + (a + b))။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println(a + b);
    }
}
