つながったサーバーのグループ

Groups of connected servers

2026-11-14 · ふつう Union-Findグラフ

問題

データセンターに 1 から N までの番号のサーバーが N 台あり、最初はどれもつながっていません。これから M 本のケーブルを順に配線します。j 本目のケーブルはサーバー aⱼ と bⱼ をつなぎます。

ケーブルで（ほかのサーバーを経由してもよいので）行き来できるサーバーどうしを 1 つのグループと考えます。ケーブルを 1 本つなぐたびに、グループがいくつあるかを出力してください。

問題 (en)

A data centre has N servers numbered 1 to N, none of them connected yet. M cables are now plugged in one after another; cable j connects servers aⱼ and bⱼ.

Servers that can reach each other through cables (possibly via other servers) form one group. After each cable, print how many groups there are.

問題 (my)

data center တစ်ခုတွင် 1 မှ N အထိ နံပါတ်တပ်ထားသော server N လုံး ရှိပြီး အစတွင် မည်သည့် server မျှ ချိတ်ဆက်မထားပါ။ ယခု cable M ကြိုးကို တစ်ကြိုးပြီးတစ်ကြိုး တပ်ဆင်မည်။ j ကြိုးမြောက် cable သည် server aⱼ နှင့် bⱼ ကို ချိတ်ဆက်သည်။

cable ဖြင့် (အခြား server များကို ဖြတ်၍လည်း ရသည်) အပြန်အလှန် သွားနိုင်သော server များကို အုပ်စုတစ်စု ဟု သတ်မှတ်သည်။ cable တစ်ကြိုး ချိတ်ပြီးတိုင်း အုပ်စု မည်မျှ ရှိသည်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, M ≤ 2×10⁵
  • 1 ≤ aⱼ, bⱼ ≤ N
  • 同じ 2 台をつなぐケーブルが何本あってもよい
  • 入力はすべて整数

入力

N M
a_1 b_1
⋮
a_M b_M

出力

M 行出力してください。j 行目には j 本目のケーブルをつないだあとのグループの数を出力してください。

入力例 1

5 4
1 2
3 4
2 1
2 3

出力例 1

4
3
3
2

3 本目のケーブルは、もう同じグループの 1 と 2 をつなぐので、数は変わりません。

1 3

出力例 2

ヒント

最初はグループが N 個です。ケーブルが別々のグループをつないだときだけ、グループが 1 つ減ります。「この 2 台は同じグループか」をすばやく調べるには？

ヒント (en)

There are N groups at the start, and the count drops by one only when a cable joins two different groups. How can you check quickly whether two servers are already in the same group?

ヒント (my)

အစတွင် အုပ်စု N စု ရှိသည်။ cable သည် မတူညီသော အုပ်စုနှစ်စု ကို ချိတ်ဆက်မှသာ အုပ်စုအရေအတွက် တစ်ခု လျော့သည်။ "ဤ server နှစ်လုံးသည် အုပ်စုတစ်စုတည်း ဖြစ်ပြီးပြီလား" ကို မြန်မြန် စစ်ရန် မည်သို့ လုပ်မည်နည်း။

解説

Union-Find（素集合データ構造）を使います。各サーバーに「親」を 1 つ持たせ、親をたどって行き着く先（根）をグループの代表にします。

  • find(x)：x の根を返す。たどりながら親を根に付け替えると（経路圧縮）、次からは速くなります。
  • union(a, b)：根が違えば、片方の根をもう片方の下につなぎ、グループの数を 1 減らします。

小さいほうの木を大きいほうの下につなぐ工夫も入れると、1 回の操作はほぼ定数時間になり、全体で O((N + M) α(N)) です（α はとても増え方の遅い関数で、実用上 5 以下）。

解説 (en)

Use Union-Find (a disjoint-set structure). Each server has one parent; following parents leads to the root, which stands for the group.

  • find(x) returns the root of x. Pointing every server on the way straight at the root (path compression) makes later calls fast.
  • union(a, b): if the roots differ, hang one root under the other and the group count drops by one.

Together with hanging the smaller tree under the larger one, each operation takes almost constant time, O((N + M) α(N)) in total (α grows so slowly that it is at most 5 in practice).

解説 (my)

Union-Find (素集合データ構造) ကို သုံးပါ။ server တစ်လုံးချင်းစီတွင် "parent" တစ်ခု ရှိပြီး parent ကို လိုက်သွားလျှင် ရောက်သော နေရာ (root) သည် အုပ်စု၏ ကိုယ်စားလှယ် ဖြစ်သည်။

  • find(x): x ၏ root ကို ပြန်ပေးသည်။ လိုက်သွားရင်း parent ကို root သို့ တိုက်ရိုက် ပြောင်းချိတ်လျှင် (path compression) နောက်တစ်ကြိမ်မှစ၍ မြန်လာသည်။
  • union(a, b): root မတူလျှင် root တစ်ခုကို နောက်တစ်ခု၏ အောက်တွင် ချိတ်ပြီး အုပ်စုအရေအတွက်ကို တစ်ခု လျှော့ပါ။

သေးသော tree ကို ကြီးသော tree အောက်တွင် ချိတ်ခြင်းကိုပါ ထည့်လျှင် လုပ်ဆောင်ချက်တစ်ခုသည် အချိန်အားဖြင့် constant နီးပါး ဖြစ်ပြီး စုစုပေါင်း O((N + M) α(N)) ဖြစ်သည် (α သည် အလွန်နှေးကွေးစွာ ကြီးသော function ဖြစ်ပြီး လက်တွေ့တွင် 5 ထက် မကျော်ပါ)။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    static int[] parent, size;

    static int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];   // path compression (halving)
            x = parent[x];
        }
        return x;
    }

    /** Joins the groups of a and b; false if they were already one group. */
    static boolean union(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) { int t = a; a = b; b = t; }
        parent[b] = a;   // the smaller tree goes under the larger one
        size[a] += size[b];
        return true;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        parent = new int[n + 1];
        size = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
            size[i] = 1;
        }

        int groups = n;
        StringBuilder out = new StringBuilder();
        for (int j = 0; j < m; j++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            if (union(a, b)) groups--;
            out.append(groups).append('\n');
        }
        System.out.print(out);
    }
}
