入門4 バグが一番多い画面

Basics 4 · The screen with the most bugs

2026-11-08 · やさしい 入門ループ最大値

問題

テストで N 個の画面を確認しました。i 番目の画面で見つかったバグは Bᵢ 件です。

バグが一番多い画面の番号を出力してください。一番多い画面が複数あるときは、番号が一番小さいものを出力してください。

問題 (en)

You tested N screens. Bᵢ bugs were found on screen i.

Print the number of the screen with the most bugs. If several screens share the largest count, print the smallest number.

問題 (my)

စမ်းသပ်မှုတွင် screen N ခုကို စစ်ဆေးခဲ့သည်။ i ခုမြောက် screen တွင် bug Bᵢ ခု တွေ့ခဲ့သည်။

bug အများဆုံး screen ၏ နံပါတ်ကို ထုတ်ပြပါ။ bug အများဆုံး screen တစ်ခုထက်ပို ရှိလျှင် နံပါတ် အငယ်ဆုံးကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 100
  • 0 ≤ Bᵢ ≤ 1000
  • 入力はすべて整数

入力

N
B_1 B_2 … B_N

出力

画面の番号（1 から N）を出力してください。

入力例 1

4
3 7 2 5

出力例 1

2

入力例 2

4
3 7 2 7

出力例 2

2

2 番と 4 番が 7 件で同じなので、小さい方の 2 を出力します。

ヒント

「今までで一番多い件数」と「その画面の番号」の 2 つを覚えながら、順番に見ていきます。新しい数が今までの最大より大きいときだけ更新しましょう。

ヒント (en)

Go through the screens in order, remembering two things: the largest count so far and the number of that screen. Update them only when the new count is larger.

ヒント (my)

ယခုထိ အများဆုံး bug အရေအတွက်နှင့် ထို screen ၏ နံပါတ် နှစ်ခုကို မှတ်ထားရင်း အစဉ်လိုက် ကြည့်ပါ။ ဂဏန်းအသစ်က ယခုထိ အများဆုံးထက် ကြီးမှသာ ပြောင်းပါ။

解説

最大値を探す基本の形です。

  • 比較に > を使うと、同じ件数のときは更新されないので、最初に出てきた（番号が小さい）画面が残ります。
  • >= にすると、最後に出てきた画面になってしまい、入力例 2 で 4 と答えてしまいます。
  • 配列の番号は 0 から、画面の番号は 1 から始まります。出力するときに + 1 を忘れないようにしましょう。

解説 (en)

This is the basic pattern for finding a maximum.

  • Comparing with > keeps the first screen on a tie, which is the smallest number.
  • With >= you keep the last one, and sample 2 would print 4.
  • Loop indexes start at 0 but screen numbers start at 1, so remember the + 1 when printing.

解説 (my)

အကြီးဆုံးတန်ဖိုး ရှာသည့် အခြေခံပုံစံ ဖြစ်သည်။

  • > ဖြင့် နှိုင်းယှဉ်လျှင် တူညီသည့်အခါ မပြောင်းသဖြင့် ပထမဆုံး (နံပါတ်အငယ်ဆုံး) screen ကျန်ပါမည်။
  • >= ကို သုံးလျှင် နောက်ဆုံး screen ဖြစ်သွားပြီး ဥပမာ ၂ တွင် 4 ဟု မှားဖြေပါမည်။
  • Loop index သည် 0 မှ စပြီး screen နံပါတ်သည် 1 မှ စသဖြင့် ထုတ်သည့်အခါ + 1 ကို မမေ့ပါနှင့်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int best = -1;      // largest count so far
        int bestNo = 0;     // screen number with that count
        for (int i = 0; i < n; i++) {
            int b = sc.nextInt();
            if (b > best) {
                best = b;
                bestNo = i + 1;
            }
        }
        System.out.println(bestNo);
    }
}
