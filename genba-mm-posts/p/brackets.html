ステップアップ6 括弧の対応チェック

Step up 6 · Do the brackets match?

2026-11-08 · ふつう ステップアップスタック文字列

問題

設定ファイルの括弧が正しく閉じられているか調べるツールを作ります。(、)、[、]、{、} だけからなる文字列 S が与えられます。

次の条件を満たすとき Yes、そうでなければ No と出力してください。

  • 開き括弧には、同じ種類の閉じ括弧が対応している
  • 内側の括弧が先に閉じられている（([)] は正しくない）

問題 (en)

You are making a tool that checks whether the brackets in a config file are closed correctly. You are given a string S made only of (, ), [, ], { and }.

Print Yes if both of these hold, otherwise No:

  • every opening bracket is matched by a closing bracket of the same kind
  • inner brackets are closed first (([)] is not correct)

問題 (my)

config file ၏ ကွင်းများကို မှန်ကန်စွာ ပိတ်ထားခြင်း ရှိမရှိ စစ်ဆေးသော tool ကို ပြုလုပ်မည်။ (၊ )၊ [၊ ]၊ {၊ } များသာ ပါဝင်သော string S ကို ပေးထားသည်။

အောက်ပါ အခြေအနေများ ပြည့်မီလျှင် Yes၊ မပြည့်မီလျှင် No ဟု ထုတ်ပြပါ။

  • ကွင်းဖွင့်တိုင်းတွင် အမျိုးအစားတူ ကွင်းပိတ် ကိုက်ညီနေသည်
  • အတွင်းဘက် ကွင်းကို အရင် ပိတ်ထားသည် (([)] သည် မမှန်ပါ)

制約

  • 1 ≤ |S| ≤ 2×10⁵
  • S は ()[]{} の 6 種類の文字だけからなる

入力

S

出力

Yes または No を出力してください。

入力例 1

{[()]}

出力例 1

Yes

入力例 2

([)]

出力例 2

No

入力例 3

((

出力例 3

No

閉じられていない括弧があります。

入力例 4

())(

出力例 4

No

ヒント

閉じ括弧が来たとき、対応するのは「一番最近開いて、まだ閉じていない括弧」です。最後に入れたものを最初に取り出せるデータ構造を使いましょう。

ヒント (en)

A closing bracket must match the most recently opened bracket that is still open. Use a data structure where the last thing you put in is the first thing you take out.

ヒント (my)

ကွင်းပိတ် ရောက်လာလျှင် ၎င်းနှင့် ကိုက်ရမည့်အရာမှာ «နောက်ဆုံးဖွင့်ခဲ့ပြီး မပိတ်ရသေးသော ကွင်း» ဖြစ်သည်။ နောက်ဆုံး ထည့်ထားသည့်အရာကို အရင်ဆုံး ပြန်ထုတ်နိုင်သော data structure ကို သုံးပါ။

解説

スタックを使います。Java では ArrayDeque<Character> の push（積む）と pop（取り出す）を使います（古い Stack クラスより速いです）。

  • 開き括弧なら積む。
  • 閉じ括弧なら、スタックが空なら No。空でなければ取り出して、種類が合わなければ No。
  • 最後までいったら、スタックが空なら Yes（入力例 3 のように残っていたら No）。

全体で O(|S|) です。コンパイラやエディタの括弧チェックも同じ仕組みです。

解説 (en)

Use a stack. In Java, ArrayDeque<Character> with push and pop (faster than the old Stack class).

  • Opening bracket: push it.
  • Closing bracket: if the stack is empty, No; otherwise pop, and if the kinds differ, No.
  • At the end, Yes only if the stack is empty (sample 3 leaves brackets on it).

This is O(|S|), and it is how compilers and editors check brackets too.

解説 (my)

Stack ကို သုံးပါ။ Java တွင် ArrayDeque<Character> ၏ push နှင့် pop ကို သုံးပါ။

  • ကွင်းဖွင့် ဖြစ်လျှင် push လုပ်ပါ။
  • ကွင်းပိတ် ဖြစ်လျှင် stack ဗလာဖြစ်နေပါက No။ မဟုတ်ပါက pop လုပ်ပြီး အမျိုးအစား မတူလျှင် No။
  • အဆုံးတွင် stack ဗလာဖြစ်မှသာ Yes (ဥပမာ ၃ ကဲ့သို့ ကျန်နေလျှင် No)။

ဤနည်း၏ အချိန်ရှုပ်ထွေးမှုမှာ O(|S|) ဖြစ်ပြီး compiler နှင့် editor များတွင်လည်း ကွင်းများ ကိုက်ညီမှု စစ်ရန် သုံးသည်။

解答 (Java)

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) {
                    System.out.println("No");
                    return;
                }
                char open = stack.pop();
                if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{')) {
                    System.out.println("No");
                    return;
                }
            }
        }
        System.out.println(stack.isEmpty() ? "Yes" : "No");
    }
}
