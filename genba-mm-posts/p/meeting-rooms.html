入門8 会議室はいくつ必要？

Basics 8 · How many meeting rooms?

2026-11-08 · やさしい 入門計算

問題

N 人で勉強会をします。会議室は 1 部屋に K 人まで入れます。全員が入るには、会議室が最低いくつ必要か出力してください。

問題 (en)

N people are holding a study session. One meeting room holds up to K people. Print the smallest number of rooms needed so that everyone fits.

問題 (my)

လူ N ယောက်ဖြင့် လေ့လာရေး အစည်းအဝေး (勉強会) လုပ်မည်။ အစည်းအဝေးခန်း တစ်ခန်းတွင် လူ K ယောက်အထိ ဝင်ဆံ့သည်။ လူအားလုံး ဝင်ဆံ့ရန် အနည်းဆုံး အခန်း မည်မျှ လိုသည်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, K ≤ 1000
  • 入力はすべて整数

入力

N K

出力

必要な会議室の数を出力してください。

入力例 1

10 4

出力例 1

3

4 人、4 人、2 人の 3 部屋です。

入力例 2

8 4

出力例 2

2

入力例 3

1 10

出力例 3

1

ヒント

Java の int 同士の割り算 / は、小数点以下を切り捨てます（10 / 4 は 2）。余りは % でわかります（10 % 4 は 2）。余りがあるときは部屋が 1 つ多く必要です。

ヒント (en)

Dividing two ints with / drops the fraction (10 / 4 is 2). % gives the remainder (10 % 4 is 2). If there is a remainder, you need one more room.

ヒント (my)

Java တွင် int နှစ်ခုကို / ဖြင့် စားလျှင် ဒသမနောက်ကို ဖြတ်ပစ်သည် (10 / 4 သည် 2)။ အကြွင်းကို % ဖြင့် သိနိုင်သည် (10 % 4 သည် 2)။ အကြွင်းရှိလျှင် အခန်း တစ်ခန်း ပိုလိုသည်။

解説

素直に書くと次のようになります。

int rooms = n / k;
if (n % k != 0) {
    rooms++;
}

よく使う書き方として、(n + k - 1) / k でも同じ答えになります。「切り上げの割り算」として覚えておくと便利です。

Math.ceil(n / k) は間違いです。n / k の時点で切り捨てられているので、Math.ceil には 2.0 が渡されます。

解説 (en)

The plain way: divide, then add one room if n % k != 0.

A common shortcut gives the same answer: (n + k - 1) / k, "division rounding up".

Math.ceil(n / k) is wrong: n / k has already been rounded down before Math.ceil sees it.

解説 (my)

ရိုးရိုးနည်း: စားပြီး n % k != 0 ဖြစ်လျှင် အခန်း တစ်ခန်း ထပ်ပေါင်းပါ။

အသုံးများသော နည်းလမ်းတိုအဖြစ် (n + k - 1) / k ဖြင့်လည်း အဖြေတူရသည် («အပေါ်သို့ ပိုင်းစားခြင်း»)။

Math.ceil(n / k) သည် မှားသည်။ Math.ceil မရောက်မီ n / k တွင် ဖြတ်ပြီးသား ဖြစ်နေသောကြောင့်ပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        int rooms = n / k;
        if (n % k != 0) {
            rooms++;
        }
        System.out.println(rooms);
    }
}
