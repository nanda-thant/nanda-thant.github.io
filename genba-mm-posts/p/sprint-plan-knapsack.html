スプリントに入れるタスク

Which tasks fit in the sprint

2026-11-14 · むずかしい 動的計画法DPナップサック

問題

次のスプリントで使える作業時間は W 時間です。候補のタスクが N 個あり、i 番目のタスクは Hᵢ 時間かかり、価値（ストーリーポイント）は Pᵢ です。

かかる時間の合計が W 以下になるようにタスクを選びます（同じタスクは 1 回だけ）。選んだタスクの価値の合計の最大値を出力してください。

問題 (en)

The next sprint has W hours of work time. There are N candidate tasks; task i takes Hᵢ hours and is worth Pᵢ story points.

Choose tasks whose hours add up to W or less (each task at most once). Print the largest total of story points you can get.

問題 (my)

နောက် sprint တွင် အလုပ်လုပ်နိုင်သော အချိန် W နာရီ ရှိသည်။ ရွေးချယ်နိုင်သော task N ခု ရှိပြီး i ခုမြောက် task သည် Hᵢ နာရီ ကြာပြီး တန်ဖိုး (story point) Pᵢ ရှိသည်။

ကြာချိန် စုစုပေါင်း W နှင့်အောက် ဖြစ်အောင် task များကို ရွေးပါ (task တစ်ခုကို တစ်ကြိမ်သာ)။ ရွေးထားသော task များ၏ တန်ဖိုး စုစုပေါင်း အများဆုံးကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 100
  • 1 ≤ W ≤ 10⁵
  • 1 ≤ Hᵢ ≤ W
  • 1 ≤ Pᵢ ≤ 10⁹
  • 入力はすべて整数

入力

N W
H_1 P_1
⋮
H_N P_N

出力

価値の合計の最大値を 1 行で出力してください。

入力例 1

4 10
5 8
4 5
6 10
3 4

出力例 1

15

2 番目と 3 番目（4 + 6 = 10 時間）を選ぶと 5 + 10 = 15 です。価値の高い順に 3 番目、1 番目と選ぶと 11 時間で入りません。

入力例 2

2 3
4 10
5 20

出力例 2

0

ヒント

選び方は 2ᴺ 通りあり、N = 100 では全部は調べられません。また、価値の高い順や「時間あたりの価値」の高い順に選ぶ方法では、入力例 1 のように最適にならないことがあります。

「最初の i 個のタスクだけを使って、合計 w 時間以内で取れる価値の最大」を表にしてみましょう。

ヒント (en)

There are 2ᴺ ways to choose, far too many for N = 100. Picking by highest value, or by value per hour, is not always best either (see sample 1).

Try a table: "the best value using only the first i tasks within w hours".

ヒント (my)

ရွေးနည်း 2ᴺ မျိုး ရှိပြီး N = 100 တွင် အားလုံးကို မစစ်နိုင်ပါ။ တန်ဖိုး မြင့်သည့်အစဉ် သို့မဟုတ် "တစ်နာရီလျှင် တန်ဖိုး" မြင့်သည့်အစဉ်ဖြင့် ရွေးသော နည်းသည်လည်း ဥပမာ 1 ကဲ့သို့ အကောင်းဆုံး မဖြစ်နိုင်ပါ။

"ပထမ task i ခုကိုသာ သုံးပြီး w နာရီအတွင်း ရနိုင်သော အများဆုံး တန်ဖိုး" ကို ဇယားအဖြစ် လုပ်ကြည့်ပါ။

解説

動的計画法（DP）で解きます。dp[w] を「ここまでのタスクから選んで、合計 w 時間以内で取れる価値の最大」とします。最初はすべて 0 です。

タスク (H, P) を 1 つ加えるたびに、w = W から H まで大きいほうから順に

dp[w] = max(dp[w], dp[w − H] + P)

と更新します（そのタスクを選ばない場合と選ぶ場合の良いほう）。w を大きいほうから回すのは、同じタスクを 2 回使わないためです。小さいほうから回すと、更新したばかりの dp[w − H] を使ってしまいます。

計算量は O(NW) で、最大 10⁷ 回ほどです。価値の合計は最大 10¹¹ なので long を使います。この形の問題はナップサック問題と呼ばれ、DP の代表的な例です。

解説 (en)

Solve it with dynamic programming (DP). Let dp[w] be the best value you can get from the tasks seen so far within w hours; it starts at 0 everywhere.

For each task (H, P), go from w = W down to H, largest first, and set

dp[w] = max(dp[w], dp[w − H] + P)

(the better of skipping the task and taking it). Going from the top down keeps each task from being used twice: going upwards would reuse a dp[w − H] that already includes this task.

That is O(NW), about 10⁷ steps at most. Totals reach 10¹¹, so use long. This is the classic 0/1 knapsack problem.

解説 (my)

DP (動的計画法 dynamic programming) ဖြင့် ဖြေရှင်းပါ။ dp[w] ကို "ယခုအထိ task များထဲမှ ရွေးပြီး w နာရီအတွင်း ရနိုင်သော အများဆုံး တန်ဖိုး" ဟု သတ်မှတ်ပါ။ အစတွင် အားလုံး 0 ဖြစ်သည်။

task (H, P) တစ်ခု ထည့်တိုင်း w = W မှ H အထိ ကြီးရာမှ ငယ်ရာသို့ အစဉ်အတိုင်း

dp[w] = max(dp[w], dp[w − H] + P)

ဟု ပြောင်းပါ (ထို task ကို မရွေးခြင်းနှင့် ရွေးခြင်း နှစ်ခုထဲမှ ပိုကောင်းသည့်ဘက်)။ w ကို ကြီးရာမှ စ၍ လှည့်ခြင်းသည် task တစ်ခုတည်းကို နှစ်ကြိမ် မသုံးမိစေရန် ဖြစ်သည်။ ငယ်ရာမှ စလျှင် ပြောင်းပြီးခါစ dp[w − H] ကို ပြန်သုံးမိမည်။

တွက်ချက်မှု O(NW) ဖြစ်ပြီး အများဆုံး 10⁷ ကြိမ်ခန့် ဖြစ်သည်။ တန်ဖိုး စုစုပေါင်း 10¹¹ အထိ ရောက်နိုင်သောကြောင့် long ကို သုံးပါ။ ဤပုံစံ ပြဿနာကို knapsack problem (ナップサック問題) ဟု ခေါ်ပြီး DP ၏ ကိုယ်စားပြု ဥပမာ ဖြစ်သည်။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int cap = Integer.parseInt(st.nextToken());

        long[] dp = new long[cap + 1];   // dp[w] = best value within w hours
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            int h = Integer.parseInt(st.nextToken());
            long p = Long.parseLong(st.nextToken());
            for (int w = cap; w >= h; w--) {   // downwards: each task at most once
                dp[w] = Math.max(dp[w], dp[w - h] + p);
            }
        }
        System.out.println(dp[cap]);
    }
}
