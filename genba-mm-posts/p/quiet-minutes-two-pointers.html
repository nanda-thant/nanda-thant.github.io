エラーの少ない時間帯

The calmest stretch of minutes

2026-11-14 · ふつう しゃくとり法尺取り法

問題

監視システムは 1 分ごとに、その 1 分間に出たエラーの件数を記録しています。N 分ぶんの記録があり、i 分目のエラーは Aᵢ 件です。

連続する何分間かを選び、その間のエラー件数の合計が K 件以下になるようにします。そのような区間のうち、最も長いものは何分間ですか。1 分も選べないときは 0 を出力してください。

問題 (en)

A monitoring system records, every minute, how many errors happened in that minute. You have records for N minutes: minute i had Aᵢ errors.

Choose a run of consecutive minutes whose errors add up to K or fewer. How many minutes long is the longest such run? Print 0 if not even one minute can be chosen.

問題 (my)

စောင့်ကြည့်စနစ် (monitoring system) တစ်ခုသည် တစ်မိနစ်ချင်းစီတွင် ထိုမိနစ်အတွင်း ဖြစ်ခဲ့သော error အရေအတွက်ကို မှတ်တမ်းတင်ထားသည်။ N မိနစ်စာ မှတ်တမ်း ရှိပြီး i မိနစ်မြောက်တွင် error Aᵢ ခု ဖြစ်ခဲ့သည်။

ဆက်တိုက်ဖြစ်သော မိနစ်များကို ရွေးပြီး ထိုအတွင်း error စုစုပေါင်းသည် K ခု နှင့်အောက် ဖြစ်ရမည်။ ထိုသို့ ရွေးနိုင်သော အပိုင်းများထဲမှ အရှည်ဆုံးသည် မည်မျှ မိနစ်ကြာသနည်း။ တစ်မိနစ်မျှ မရွေးနိုင်လျှင် 0 ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 2×10⁵
  • 0 ≤ Aᵢ ≤ 10⁹
  • 0 ≤ K ≤ 10¹⁴
  • 入力はすべて整数

入力

N K
A_1 A_2 … A_N

出力

最も長い区間の長さ（分）を 1 行で出力してください。

入力例 1

7 5
2 0 3 1 4 0 1

出力例 1

3

たとえば 2, 0, 3（合計 5）や 4, 0, 1（合計 5）が 3 分間です。4 分間の区間はどれも合計が 5 を超えます。

入力例 2

3 0
1 2 3

出力例 2

0

入力例 3

4 10
1 1 1 1

出力例 3

4

ヒント

区間の左端を 1 つ右に動かすと、右端はそれより左に戻る必要がありません。左端と右端の 2 本の指を、どちらも右にだけ動かしてみましょう。

ヒント (en)

When the left end of the range moves one step right, the right end never has to move back left. Try moving two fingers, the left end and the right end, only ever to the right.

ヒント (my)

အပိုင်း၏ ဘယ်ဘက်အစွန်းကို ညာဘက်သို့ တစ်နေရာ ရွှေ့လိုက်လျှင် ညာဘက်အစွန်းသည် ဘယ်ဘက်သို့ ပြန်ဆုတ်ရန် မလိုပါ။ ဘယ်အစွန်းနှင့် ညာအစွန်း လက်ချောင်းနှစ်ချောင်းကို ညာဘက်သို့သာ ရွှေ့ကြည့်ပါ။

解説

すべての区間を調べると O(N²) で、N = 2×10⁵ では間に合いません。

件数はどれも 0 以上なので、区間を広げると合計は増え、縮めると減ります。そこで右端 right を 1 つずつ進めて A を足し、合計が K を超えたら、K 以下に戻るまで左端 left を進めて A を引きます。こうすると、どの右端についても「そこで終わる一番長い区間」が left から right までになります。

left も right も N 回しか進まないので、全体で O(N) です。この方法をしゃくとり法（尺取り法）と呼びます。合計は最大で 2×10⁵ × 10⁹ になるので、long を使います。

解説 (en)

Checking every range is O(N²), too slow for N = 2×10⁵.

Every count is 0 or more, so a wider range never has a smaller total. Move the right end one step at a time and add A; whenever the total goes over K, move the left end and subtract until it is K or less again. For each right end, left…right is then the longest range ending there.

Both ends move at most N times, so the whole thing is O(N). This is the two-pointer (sliding window) technique, called しゃくとり法 in Japanese. The total can reach 2×10⁵ × 10⁹, so use long.

解説 (my)

အပိုင်းအားလုံးကို စစ်လျှင် O(N²) ဖြစ်ပြီး N = 2×10⁵ အတွက် အချိန်မမီပါ။

အရေအတွက်အားလုံးသည် 0 နှင့်အထက် ဖြစ်သောကြောင့် အပိုင်းကို ချဲ့လျှင် စုစုပေါင်း မလျော့ပါ။ ညာအစွန်း right ကို တစ်နေရာချင်း ရွှေ့ပြီး A ကို ပေါင်းပါ။ စုစုပေါင်းသည် K ထက် ကျော်သွားလျှင် K နှင့်အောက် ပြန်ဖြစ်သည်အထိ ဘယ်အစွန်း left ကို ရွှေ့ပြီး A ကို နုတ်ပါ။ ထိုအခါ ညာအစွန်းတိုင်းအတွက် left မှ right အထိသည် ထိုနေရာတွင် ဆုံးသော အရှည်ဆုံး အပိုင်း ဖြစ်သည်။

အစွန်းနှစ်ဖက်စလုံး N ကြိမ်သာ ရွှေ့သောကြောင့် စုစုပေါင်း O(N) ဖြစ်သည်။ ဤနည်းကို two pointers (しゃくとり法) ဟု ခေါ်သည်။ စုစုပေါင်းသည် 2×10⁵ × 10⁹ အထိ ရောက်နိုင်သောကြောင့် long ကို သုံးပါ။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        long k = Long.parseLong(st.nextToken());

        long[] a = new long[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) a[i] = Long.parseLong(st.nextToken());

        long sum = 0;   // errors in a[left..right]
        int left = 0, best = 0;
        for (int right = 0; right < n; right++) {
            sum += a[right];
            while (sum > k) sum -= a[left++];      // shrink until the total is K or less
            best = Math.max(best, right - left + 1);  // an empty range (left > right) counts as 0
        }
        System.out.println(best);
    }
}
