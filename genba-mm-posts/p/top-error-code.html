ステップアップ2 一番多いエラーコード

Step up 2 · The most frequent error code

2026-11-08 · ふつう ステップアップHashMap文字列

問題

障害ログに N 件のエラーコード Cᵢ が記録されています。一番多く出てきたエラーコードを出力してください。

同じ回数のものが複数あるときは、辞書順で一番小さいものを出力してください。

問題 (en)

An incident log records N error codes Cᵢ. Print the error code that appears most often.

If several codes appear the same number of times, print the one that comes first in dictionary order.

問題 (my)

ချို့ယွင်းချက် log (障害ログ) တွင် error code Cᵢ N ခု မှတ်တမ်းတင်ထားသည်။ အကြိမ်အများဆုံး ပေါ်သော error code ကို ထုတ်ပြပါ။

အကြိမ်ရေ တူသော code တစ်ခုထက်ပို ရှိလျှင် dictionary order (အက္ခရာစဉ်) အရ အငယ်ဆုံးကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 2×10⁵
  • Cᵢ は英大文字と数字からなる 1〜10 文字の文字列

入力

N
C_1 C_2 … C_N

出力

エラーコードを出力してください。

入力例 1

6
E404 E500 E404 E503 E500 E404

出力例 1

E404

入力例 2

4
B2 A1 B2 A1

出力例 2

A1

A1 と B2 が 2 回ずつなので、辞書順で小さい A1 です。

ヒント

コードは数字ではなく文字列なので、ステップアップ1 のように配列の添字には使えません。「文字列 → 回数」を覚えておける HashMap<String, Integer> を使いましょう。

ヒント (en)

The codes are strings, not numbers, so they cannot be array indexes as in Step up 1. Use a HashMap<String, Integer> that maps each code to its count.

ヒント (my)

Code များသည် ဂဏန်းမဟုတ်ဘဲ string ဖြစ်သဖြင့် အဆင့်မြှင့် ၁ ကဲ့သို့ array index အဖြစ် မသုံးနိုင်ပါ။ «string → အကြိမ်ရေ» ကို မှတ်ထားနိုင်သော HashMap<String, Integer> ကို သုံးပါ။

解説

Map<String, Integer> count = new HashMap<>();
count.merge(code, 1, Integer::sum);   // なければ 1、あれば +1

count.put(code, count.getOrDefault(code, 0) + 1) と書いても同じです。

最後に全部のエントリを見て、回数が多いもの、同じなら compareTo で小さいものを選びます。a.compareTo(b) < 0 は「a が辞書順で b より前」という意味です。

HashMap の追加・検索は平均 O(1) なので、全体で O(N) です。HashMap は順番を保証しないので、「辞書順で最小」は自分で比べる必要があります。

解説 (en)

count.merge(code, 1, Integer::sum) adds 1, starting from 1 for a new code. count.put(code, count.getOrDefault(code, 0) + 1) does the same.

Then look at every entry and keep the one with the highest count, using compareTo on ties: a.compareTo(b) < 0 means a comes before b in dictionary order.

HashMap insert and lookup take O(1) on average, so the whole program is O(N). A HashMap has no order, so you must compare for "smallest in dictionary order" yourself.

解説 (my)

count.merge(code, 1, Integer::sum) သည် code အသစ်ဆိုလျှင် 1၊ ရှိပြီးသားဆိုလျှင် +1 လုပ်သည်။

နောက်ဆုံးတွင် entry အားလုံးကို ကြည့်ပြီး အကြိမ်ရေ အများဆုံးကို ရွေးပါ။ တူလျှင် compareTo ဖြင့် ငယ်သည့်တစ်ခုကို ရွေးပါ။ a.compareTo(b) < 0 ဆိုသည်မှာ အက္ခရာစဉ်အရ a သည် b ၏ ရှေ့တွင် ရှိသည်ဟု ဆိုလိုသည်။

HashMap တွင် ထည့်ခြင်း၊ ရှာခြင်းသည် ပျမ်းမျှ O(1) ဖြစ်သဖြင့် စုစုပေါင်း O(N) ဖြစ်သည်။

count.put(code, count.getOrDefault(code, 0) + 1) ဖြင့်လည်း တူညီစွာ ရေတွက်နိုင်သည်။ HashMap မှာ အစဉ်လိုက်စီထားခြင်း မရှိသဖြင့် အက္ခရာစဉ်အရ အငယ်ဆုံးကို ကိုယ်တိုင် နှိုင်းယှဉ်ရွေးရမည်။

解答 (Java)

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Map<String, Integer> count = new HashMap<>();
        for (int i = 0; i < n; i++) {
            count.merge(sc.next(), 1, Integer::sum);
        }
        String best = null;
        int bestCount = 0;
        for (Map.Entry<String, Integer> e : count.entrySet()) {
            String code = e.getKey();
            int c = e.getValue();
            if (c > bestCount || (c == bestCount && code.compareTo(best) < 0)) {
                best = code;
                bestCount = c;
            }
        }
        System.out.println(best);
    }
}
