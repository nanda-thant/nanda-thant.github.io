入門9 平均より時間がかかったタスク

Basics 9 · Tasks that took longer than average

2026-11-08 · やさしい 入門配列

問題

N 個のタスクがあり、i 番目のタスクには Tᵢ 時間かかりました。かかった時間が平均より長いタスクはいくつありますか。

問題 (en)

There are N tasks, and task i took Tᵢ hours. How many tasks took longer than the average?

問題 (my)

task N ခု ရှိပြီး i ခုမြောက် task သည် Tᵢ နာရီ ကြာခဲ့သည်။ ကြာချိန်သည် ပျမ်းမျှထက် ပိုကြာ သော task မည်မျှ ရှိသနည်း။

制約

  • 1 ≤ N ≤ 100
  • 1 ≤ Tᵢ ≤ 100
  • 入力はすべて整数

入力

N
T_1 T_2 … T_N

出力

平均より長いタスクの数を出力してください。

入力例 1

4
2 4 6 8

出力例 1

2

平均は 5 時間なので、6 と 8 の 2 つです。

入力例 2

3
5 5 5

出力例 2

0

入力例 3

3
1 1 2

出力例 3

1

平均は 1.333… 時間です。

ヒント

平均は全部読んでからでないとわかりません。読んだ数を配列に入れておけば、あとでもう一度見られます。int[] t = new int[n];

ヒント (en)

You only know the average after reading every number, so keep them in an array to look at them again: int[] t = new int[n];

ヒント (my)

ပျမ်းမျှကို ဂဏန်းအားလုံး ဖတ်ပြီးမှသာ သိနိုင်သည်။ ထို့ကြောင့် ဂဏန်းများကို array ထဲ သိမ်းထားပြီး နောက်တစ်ကြိမ် ပြန်ကြည့်ပါ: int[] t = new int[n];

解説

1 回目のループで配列に入れながら合計を出し、2 回目のループで平均と比べます。

平均は 1.333… のように割り切れないことがあります。Tᵢ > 合計 / N の両辺に N を掛けて Tᵢ × N > 合計 と比べると、小数を使わずに正確に判定できます。int の割り算は切り捨てなので、t[i] > sum / n と書くと入力例 3 で間違えます。

解説 (en)

Loop once to fill the array and add up the total, then loop again to compare.

The average can be 1.333…, so multiply both sides by N and compare Tᵢ × N > total: exact, with no decimals. Since int division rounds down, t[i] > sum / n would get sample 3 wrong.

解説 (my)

ပထမ loop တွင် array ထဲ ထည့်ရင်း စုစုပေါင်းကို တွက်ပြီး ဒုတိယ loop တွင် နှိုင်းယှဉ်ပါ။

ပျမ်းမျှသည် 1.333… ကဲ့သို့ ဖြစ်နိုင်သဖြင့် ဘက်နှစ်ဘက်လုံးကို N ဖြင့် မြှောက်ပြီး Tᵢ × N > စုစုပေါင်း ဟု နှိုင်းယှဉ်လျှင် ဒသမမသုံးဘဲ တိကျစွာ စစ်နိုင်သည်။ t[i] > sum / n ဟု ရေးလျှင် ဥပမာ ၃ တွင် မှားပါမည်။

int ဖြင့် စားလျှင် ဒသမအပိုင်းကို ဖြတ်ပစ်သောကြောင့် ဖြစ်သည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] t = new int[n];
        int sum = 0;
        for (int i = 0; i < n; i++) {
            t[i] = sc.nextInt();
            sum += t[i];
        }
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (t[i] * n > sum) {
                count++;
            }
        }
        System.out.println(count);
    }
}
