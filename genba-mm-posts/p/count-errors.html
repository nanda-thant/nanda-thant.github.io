入門5 ログの ERROR を数える

Basics 5 · Count the ERROR lines

2026-11-08 · やさしい 入門文字列

問題

サーバーのログが N 行あります。各行にはログレベル INFO、WARN、ERROR のどれか 1 つが書かれています。

ERROR の行がいくつあるか出力してください。

問題 (en)

A server log has N lines. Each line has one log level: INFO, WARN or ERROR.

Print how many lines are ERROR.

問題 (my)

server log တွင် စာကြောင်း N ကြောင်း ရှိသည်။ စာကြောင်းတိုင်းတွင် log level INFO၊ WARN၊ ERROR ထဲမှ တစ်ခု ရေးထားသည်။

ERROR စာကြောင်း မည်မျှ ရှိသည်ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 100
  • 各行は INFO、WARN、ERROR のどれか

入力

N
L_1
L_2
⋮
L_N

出力

ERROR の行の数を出力してください。

入力例 1

5
INFO
ERROR
WARN
ERROR
INFO

出力例 1

2

入力例 2

2
INFO
WARN

出力例 2

0

ヒント

文字列は sc.next() で読めます。Java で文字列が同じかどうかを調べるときは、== ではなく equals を使います。

ヒント (en)

Read a word with sc.next(). To check whether two strings are the same in Java, use equals, not ==.

ヒント (my)

စကားလုံးကို sc.next() ဖြင့် ဖတ်နိုင်သည်။ Java တွင် string နှစ်ခု တူမတူ စစ်ရန် == မဟုတ်ဘဲ equals ကို သုံးပါ။

解説

Java の == は「同じオブジェクトかどうか」を比べます。読み込んだ文字列は毎回新しいオブジェクトなので、中身が ERROR でも s == "ERROR" は false になることがあります。

中身を比べるには "ERROR".equals(s) と書きます。定数を左に書くと、s が null でもエラーになりません。これは実務の Java でもよく使う書き方です。

解説 (en)

In Java, == checks whether two strings are the same object. Each string you read is a new object, so s == "ERROR" can be false even when s holds ERROR.

Compare the contents with "ERROR".equals(s). Putting the constant on the left also avoids a crash when s is null, a habit worth keeping in real Java code too.

解説 (my)

Java တွင် == သည် object တစ်ခုတည်း ဟုတ်မဟုတ်ကို နှိုင်းယှဉ်သည်။ ဖတ်လိုက်သော string တိုင်းသည် object အသစ်ဖြစ်သဖြင့် အထဲတွင် ERROR ရှိသော်လည်း s == "ERROR" သည် false ဖြစ်နိုင်သည်။

အကြောင်းအရာကို နှိုင်းယှဉ်ရန် "ERROR".equals(s) ဟု ရေးပါ။ Constant ကို ဘယ်ဘက်တွင် ထားလျှင် s သည် null ဖြစ်နေသော်လည်း error မတက်ပါ။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int count = 0;
        for (int i = 0; i < n; i++) {
            String level = sc.next();
            if ("ERROR".equals(level)) {
                count++;
            }
        }
        System.out.println(count);
    }
}
