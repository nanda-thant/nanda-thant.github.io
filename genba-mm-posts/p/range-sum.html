区間の売上合計

Sales in a range of days

2026-11-08 · ふつう 累積和配列

問題

あるお店の N 日間の売上が与えられます。i 日目の売上は Aᵢ 円です。

Q 個の質問に答えてください。j 番目の質問では整数 Lⱼ, Rⱼ が与えられるので、Lⱼ 日目から Rⱼ 日目までの売上の合計を出力してください。

問題 (en)

You are given a shop's sales for N days; the sales on day i are Aᵢ yen.

Answer Q questions. Question j gives integers Lⱼ and Rⱼ: print the total sales from day Lⱼ to day Rⱼ.

問題 (my)

ဆိုင်တစ်ဆိုင်၏ N ရက်စာ ရောင်းအားကို ပေးထားသည်။ i ရက်မြောက်နေ့၏ ရောင်းအားသည် Aᵢ ယန်း ဖြစ်သည်။

မေးခွန်း Q ခုကို ဖြေပါ။ j ခုမြောက် မေးခွန်းတွင် ကိန်းပြည့် Lⱼ, Rⱼ ကို ပေးထားသောကြောင့် Lⱼ ရက်မြောက်မှ Rⱼ ရက်မြောက်အထိ ရောင်းအား စုစုပေါင်းကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, Q ≤ 2×10⁵
  • 0 ≤ Aᵢ ≤ 10⁹
  • 1 ≤ Lⱼ ≤ Rⱼ ≤ N
  • 入力はすべて整数

入力

N Q
A_1 A_2 … A_N
L_1 R_1
⋮
L_Q R_Q

出力

Q 行出力してください。j 行目には j 番目の質問の答えを出力してください。

入力例 1

5 3
3 1 4 1 5
1 3
2 5
4 4

出力例 1

8
11
1

1 日目から 3 日目までの売上は 3 + 1 + 4 = 8 円です。

ヒント

質問ごとに足し算をすると、最大で 2×10⁵ × 2×10⁵ = 4×10¹⁰ 回の計算になり、間に合いません。先に何かを計算しておけないでしょうか。

ヒント (en)

Adding up the range for every question can take 4×10¹⁰ steps, which is too slow. What could you calculate once, before reading the questions?

ヒント (my)

မေးခွန်းတစ်ခုချင်းစီအတွက် ပေါင်းနေလျှင် အကြိမ် 4×10¹⁰ အထိ တွက်ရပြီး အချိန်မမီပါ။ မေးခွန်းများ မဖတ်မီ တစ်ကြိမ်တည်း ကြိုတွက်ထားနိုင်သည့်အရာ ရှိပါသလား။

解説

累積和を使います。S₀ = 0、Sᵢ = A₁ + A₂ + … + Aᵢ とすると、L 日目から R 日目までの合計は S_R − S_{L−1} です。

S は最初に O(N) で作れるので、各質問には O(1) で答えられます。全体の計算量は O(N + Q) です。

合計は最大で 2×10⁵ × 10⁹ = 2×10¹⁴ になり、int には入りません。long を使いましょう。入力が多いので、Scanner ではなく BufferedReader で読むと速くなります。

解説 (en)

Use prefix sums (累積和). With S₀ = 0 and Sᵢ = A₁ + … + Aᵢ, the total from day L to day R is S_R − S_{L−1}. Building S takes O(N), and then each question takes O(1), so the whole program is O(N + Q).

A total can reach 2×10¹⁴, which does not fit in an int: use long. The input is large, so read it with BufferedReader rather than Scanner.

解説 (my)

累積和 (prefix sum) ကို သုံးပါ။ S₀ = 0၊ Sᵢ = A₁ + … + Aᵢ ဟု ထားလျှင် L ရက်မှ R ရက်အထိ စုစုပေါင်းမှာ S_R − S_{L−1} ဖြစ်သည်။ S ကို O(N) ဖြင့် ကြိုတည်ဆောက်ပြီးနောက် မေးခွန်းတစ်ခုကို O(1) ဖြင့် ဖြေနိုင်သည်။

စုစုပေါင်းသည် 2×10¹⁴ အထိ ရောက်နိုင်သဖြင့် int ထဲ မဆံ့ပါ။ long ကို သုံးပါ။

Input ပမာဏ ကြီးမားသဖြင့် Scanner ထက် BufferedReader ကို သုံးပြီး ဖတ်ခြင်းက ပိုသင့်တော်သည်။

解答 (Java)

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int q = Integer.parseInt(st.nextToken());

        long[] sum = new long[n + 1];          // sum[i] = A_1 + ... + A_i
        st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= n; i++) {
            sum[i] = sum[i - 1] + Long.parseLong(st.nextToken());
        }

        StringBuilder out = new StringBuilder();
        for (int j = 0; j < q; j++) {
            st = new StringTokenizer(br.readLine());
            int l = Integer.parseInt(st.nextToken());
            int r = Integer.parseInt(st.nextToken());
            out.append(sum[r] - sum[l - 1]).append('\n');
        }
        System.out.print(out);
    }
}
