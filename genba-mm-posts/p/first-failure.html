入門13 最初に失敗したテスト

Basics 13 · The first failed test

2026-11-08 · やさしい 入門ループ

問題

N 個のテストを順番に実行しました。i 番目の結果 Rᵢ は OK か NG です。

最初に NG になったテストの番号を出力してください。全部 OK なら ALL OK と出力してください。

問題 (en)

You ran N tests in order. The result Rᵢ of test i is OK or NG.

Print the number of the first test that was NG. If all of them are OK, print ALL OK.

問題 (my)

test N ခုကို အစဉ်လိုက် run ခဲ့သည်။ i ခုမြောက် ရလဒ် Rᵢ သည် OK သို့မဟုတ် NG ဖြစ်သည်။

ပထမဆုံး NG ဖြစ်သော test ၏ နံပါတ်ကို ထုတ်ပြပါ။ အားလုံး OK ဖြစ်လျှင် ALL OK ဟု ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 100
  • Rᵢ は OK または NG

入力

N
R_1 R_2 … R_N

出力

最初の NG の番号（1 から N）、または ALL OK を出力してください。

入力例 1

5
OK OK NG OK NG

出力例 1

3

入力例 2

3
OK OK OK

出力例 2

ALL OK

ヒント

見つかった番号を入れる変数を、「まだ見つかっていない」を表す値（たとえば -1）で始めます。NG を見つけたら番号を入れて、break でループを抜けましょう。

ヒント (en)

Start a variable at a value meaning "not found yet", such as -1. When you see NG, store its number and leave the loop with break.

ヒント (my)

ရှာတွေ့သည့် နံပါတ်အတွက် variable ကို «မတွေ့သေး» ဟု ဆိုလိုသော တန်ဖိုး (ဥပမာ -1) ဖြင့် စပါ။ NG ကို တွေ့လျှင် နံပါတ်ကို သိမ်းပြီး break ဖြင့် loop မှ ထွက်ပါ။

解説

break はいちばん内側のループをすぐに終わらせます。最初の 1 つだけ欲しいときに、残りを調べずにすみます。

break を忘れると、最後の NG（入力例 1 では 5）が答えになってしまいます。

ループの後で -1 のままなら一度も見つからなかったので、ALL OK を出力します。このように「見つかったかどうか」を表す変数をフラグと呼びます。boolean found = false; を使っても同じことができます。

解説 (en)

break ends the innermost loop at once, so you stop at the first match without checking the rest.

Without break, you would print the last NG (5 in sample 1).

If the variable is still -1 after the loop, nothing was found, so print ALL OK. A variable like this is called a flag; boolean found = false; works too.

解説 (my)

break သည် အတွင်းဆုံး loop ကို ချက်ချင်း ရပ်စေသည်။ ပထမဆုံး တစ်ခုသာ လိုလျှင် ကျန်တာ ဆက်မစစ်ရတော့ပါ။

break မေ့လျှင် နောက်ဆုံး NG (ဥပမာ ၁ တွင် 5) ကို ဖြေမိပါမည်။

Loop ပြီးနောက် -1 အတိုင်း ရှိနေလျှင် တစ်ခုမှ မတွေ့သဖြင့် ALL OK ကို ထုတ်ပါ။ ဤကဲ့သို့ variable ကို flag ဟုခေါ်သည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int first = -1;
        for (int i = 1; i <= n; i++) {
            String r = sc.next();
            if (r.equals("NG")) {
                first = i;
                break;
            }
        }
        if (first == -1) {
            System.out.println("ALL OK");
        } else {
            System.out.println(first);
        }
    }
}
