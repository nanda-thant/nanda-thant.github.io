ステップアップ10 予算内で機材をそろえる

Step up 10 · Equipment within the budget

2026-11-08 · ふつう ステップアップ全探索

問題

新しいメンバーのために、ノート PC、モニター、キーボードを 1 つずつ買います。ノート PC は N 種類（価格 Aᵢ）、モニターは M 種類（価格 Bⱼ）、キーボードは L 種類（価格 Cₖ）あります。

合計が予算 X 円以下になる買い方のうち、合計金額の最大値を出力してください。どう買っても予算を超えるときは -1 を出力してください。

問題 (en)

For a new team member you buy one laptop, one monitor and one keyboard. There are N laptops (prices Aᵢ), M monitors (prices Bⱼ) and L keyboards (prices Cₖ).

Among the ways to buy whose total is within the budget of X yen, print the largest total. If every way goes over the budget, print -1.

問題 (my)

အဖွဲ့ဝင်သစ်အတွက် laptop၊ monitor နှင့် keyboard တစ်ခုစီ ဝယ်မည်။ laptop N မျိုး (ဈေးနှုန်း Aᵢ)၊ monitor M မျိုး (ဈေးနှုန်း Bⱼ)၊ keyboard L မျိုး (ဈေးနှုန်း Cₖ) ရှိသည်။

စုစုပေါင်း ဘတ်ဂျက် X ယန်း နှင့်အောက် ဖြစ်သော ဝယ်နည်းများထဲမှ စုစုပေါင်း ငွေပမာဏ အများဆုံးကို ထုတ်ပြပါ။ မည်သို့ ဝယ်ဝယ် ဘတ်ဂျက် ကျော်လျှင် -1 ကို ထုတ်ပြပါ။

制約

  • 1 ≤ N, M, L ≤ 100
  • 1 ≤ Aᵢ, Bⱼ, Cₖ ≤ 10⁶
  • 1 ≤ X ≤ 3×10⁶
  • 入力はすべて整数

入力

N M L X
A_1 … A_N
B_1 … B_M
C_1 … C_L

出力

合計金額の最大値、または -1 を出力してください。

入力例 1

3 2 2 100
50 70 30
20 40
10 25

出力例 1

100

70 + 20 + 10 = 100 円、または 50 + 40 + 10 = 100 円です。

入力例 2

1 1 1 10
5
5
5

出力例 2

-1

ヒント

組み合わせは最大 100 × 100 × 100 = 10⁶ 通りです。これなら全部調べても十分間に合います。

ヒント (en)

There are at most 100 × 100 × 100 = 10⁶ combinations, few enough to try them all.

ヒント (my)

ပေါင်းစပ်မှုသည် အများဆုံး 100 × 100 × 100 = 10⁶ မျိုးသာ ရှိသဖြင့် အားလုံးကို စစ်လည်း အချိန်မီပါသည်။

解説

三重ループで全部の組を調べ、予算以内で一番大きい合計を覚えておきます（全探索）。答えの初期値を -1 にしておけば、1 つも見つからないときにそのまま出力できます。

全探索は、まず組み合わせの数を数えてから使います。10⁶ なら一瞬、10⁸ でぎりぎり、10¹⁰ なら無理です。たとえば各 10⁵ 種類あれば 10¹⁵ 通りになり、ソートと二分探索のような工夫が必要になります。それがこの次の「ふつう」の問題です。

解説 (en)

Try every combination with three nested loops and keep the largest total within the budget (brute force). Starting the answer at -1 means you can print it as is when nothing fits.

Before using brute force, count the combinations: 10⁶ is instant, 10⁸ is borderline, 10¹⁰ is too slow. With 10⁵ of each item there would be 10¹⁵ combinations, and you would need ideas like sorting and binary search. That is what the ふつう problems after this one are about.

解説 (my)

Nested loop သုံးထပ်ဖြင့် ပေါင်းစပ်မှုအားလုံးကို စစ်ပြီး ဘတ်ဂျက်အတွင်း အကြီးဆုံး စုစုပေါင်းကို မှတ်ထားပါ (全探索)။ အဖြေကို -1 ဖြင့် စထားလျှင် တစ်ခုမှ မတွေ့သည့်အခါ ဒီအတိုင်း ထုတ်နိုင်သည်။

全探索 မသုံးမီ ပေါင်းစပ်မှု အရေအတွက်ကို အရင်တွက်ပါ: 10⁶ ဆိုလျှင် ချက်ချင်း၊ 10⁸ ဆိုလျှင် နယ်စပ်၊ 10¹⁰ ဆိုလျှင် မဖြစ်နိုင်ပါ။ ထိုအခါ sort နှင့် binary search ကဲ့သို့ နည်းလမ်းများ လိုအပ်ပြီး ၎င်းတို့ကို နောက် «ふつう» ပုစ္ဆာများတွင် လေ့လာပါ။

ပစ္စည်းတစ်မျိုးစီ 10⁵ ခု ရှိလျှင် ပေါင်းစပ်မှု 10¹⁵ မျိုး ဖြစ်နိုင်သဖြင့် sort နှင့် binary search ကဲ့သို့ ပိုထိရောက်သောနည်းများ လိုအပ်သည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    static int[] read(Scanner sc, int n) {
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        return a;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt(), l = sc.nextInt(), x = sc.nextInt();
        int[] a = read(sc, n), b = read(sc, m), c = read(sc, l);
        int best = -1;
        for (int pc : a) {
            for (int monitor : b) {
                for (int keyboard : c) {
                    int total = pc + monitor + keyboard;
                    if (total <= x && total > best) {
                        best = total;
                    }
                }
            }
        }
        System.out.println(best);
    }
}
