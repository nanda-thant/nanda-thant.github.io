入門14 ペアプロの組み合わせ

Basics 14 · Pair-programming pairs

2026-11-08 · やさしい 入門ループ全探索

問題

チームに N 人のエンジニアがいて、i 番目の人の経験年数は Aᵢ 年です。2 人でペアを作るとき、2 人の経験年数の合計がちょうど X 年になるペアは何組ありますか。

同じ 2 人の順番を入れ替えたものは同じペアとして数えます。

問題 (en)

A team has N engineers, and engineer i has Aᵢ years of experience. How many pairs of two people have exactly X years of experience in total?

The same two people in the other order count as the same pair.

問題 (my)

အဖွဲ့တွင် engineer N ယောက် ရှိပြီး i ယောက်မြောက်၏ အတွေ့အကြုံသည် Aᵢ နှစ် ဖြစ်သည်။ နှစ်ယောက်တွဲ (pair) ဖွဲ့သောအခါ နှစ်ယောက်၏ အတွေ့အကြုံ စုစုပေါင်း X နှစ် အတိအကျ ဖြစ်သော pair မည်မျှ ရှိသနည်း။

လူနှစ်ယောက်တည်းကို အစဉ်ပြောင်းထားခြင်းကို pair တစ်ခုတည်းအဖြစ် ရေတွက်ပါ။

制約

  • 2 ≤ N ≤ 100
  • 1 ≤ Aᵢ, X ≤ 100
  • 入力はすべて整数

入力

N X
A_1 A_2 … A_N

出力

ペアの数を出力してください。

入力例 1

5 10
3 7 5 5 2

出力例 1

2

（3 年, 7 年）と（5 年, 5 年）の 2 組です。

入力例 2

3 4
2 2 2

出力例 2

3

1 番と 2 番、1 番と 3 番、2 番と 3 番の 3 組です。

ヒント

ループの中にループを書く（二重ループ）と、すべての 2 人の組を調べられます。同じペアを 2 回数えないように、2 人目は 1 人目より後ろの人だけにしましょう。

ヒント (en)

A loop inside a loop (a nested loop) visits every pair. To count each pair once, let the second person start after the first one.

ヒント (my)

Loop တစ်ခုအတွင်း loop နောက်တစ်ခု (nested loop) ရေးလျှင် လူနှစ်ယောက်တွဲ အားလုံးကို စစ်နိုင်သည်။ အတွဲတစ်တွဲကို နှစ်ခါ မရေတွက်မိစေရန် ဒုတိယလူကို ပထမလူ၏ နောက်ကလူများသာ ယူပါ။

解説

for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (a[i] + a[j] == x) count++;
    }
}

j を i + 1 から始めるのがポイントです。j = 0 から始めると、同じペアを 2 回数え、さらに自分自身とのペアまで数えてしまいます。

このように「考えられるものを全部調べる」方法を全探索と呼びます。調べる組の数は約 N² / 2 です。N = 100 なら約 5000 通りで一瞬ですが、N = 10⁵ になると約 50 億通りで間に合いません。そのときはもっと工夫が必要です（ステップアップ編で扱います）。

解説 (en)

Starting j at i + 1 is the key. From j = 0 you would count each pair twice and also pair people with themselves.

Checking every possibility like this is called brute force (全探索). It checks about N² / 2 pairs: about 5000 for N = 100, which is instant, but about 5 billion for N = 10⁵, which is too slow. That needs a smarter idea, as in the ステップアップ series.

解説 (my)

j ကို i + 1 မှ စခြင်းသည် အဓိကဖြစ်သည်။ j = 0 မှ စလျှင် အတွဲတစ်တွဲကို နှစ်ခါ ရေတွက်ပြီး မိမိကိုယ်တိုင်နှင့်ပါ တွဲမိပါမည်။

ဖြစ်နိုင်သမျှ အားလုံးကို စစ်သည့်နည်းကို 全探索 (brute force) ဟုခေါ်သည်။ စစ်ရသည့် အတွဲ အရေအတွက်မှာ N² / 2 ခန့် ဖြစ်သည်။ N = 100 ဆိုလျှင် ၅၀၀၀ ခန့်သာ ဖြစ်သော်လည်း N = 10⁵ ဆိုလျှင် အလွန်များပြီး အချိန်မမီပါ။

N = 10⁵ ဆိုလျှင် အတွဲ 5 billion ခန့် ရှိပြီး အချိန်မမီသောကြောင့် ပိုထိရောက်သည့် နည်းလမ်း လိုအပ်သည်။ ဤအကြောင်းကို ステップアップ အပိုင်းတွင် ဆက်လေ့လာနိုင်သည်။

解答 (Java)

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int x = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        int count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (a[i] + a[j] == x) {
                    count++;
                }
            }
        }
        System.out.println(count);
    }
}
