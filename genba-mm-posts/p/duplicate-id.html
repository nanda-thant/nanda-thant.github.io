ステップアップ3 重複した社員ID

Step up 3 · A duplicated employee ID

2026-11-08 · ふつう ステップアップHashSet

問題

CSV から N 件の社員 ID を順番に取り込みます。すでに取り込んだ ID がもう一度出てきたら、そこでエラーになります。

最初にエラーになる ID を出力してください。重複がなければ NONE と出力してください。

問題 (en)

You import N employee IDs from a CSV file, one after another. If an ID that was already imported appears again, the import fails at that point.

Print the first ID that causes an error. If there are no duplicates, print NONE.

問題 (my)

CSV မှ ဝန်ထမ်း ID N ခုကို အစဉ်လိုက် ထည့်သွင်း (import) သည်။ ထည့်ပြီးသား ID တစ်ခု ထပ်ပေါ်လာလျှင် ထိုနေရာတွင် error ဖြစ်သည်။

ပထမဆုံး error ဖြစ်စေသော ID ကို ထုတ်ပြပါ။ ထပ်နေသော ID မရှိလျှင် NONE ဟု ထုတ်ပြပါ။

制約

  • 1 ≤ N ≤ 2×10⁵
  • 各 ID は英小文字と数字からなる 1〜10 文字の文字列

入力

N
D_1 D_2 … D_N

出力

最初に重複した ID、または NONE を出力してください。

入力例 1

5
u3 u1 u4 u1 u3

出力例 1

u1

4 件目の u1 で初めて重複します。u3 も重複していますが、5 件目なので後です。

入力例 2

3
a b c

出力例 2

NONE

ヒント

「今までに出てきた ID」を、すぐに調べられる形で覚えておきましょう。配列やリストで毎回全部探すと、最悪 N² / 2 ≒ 2×10¹⁰ 回になります。

ヒント (en)

Remember the IDs seen so far in a form you can check instantly. Searching a list each time costs up to N² / 2 ≈ 2×10¹⁰ steps.

ヒント (my)

ယခုထိ တွေ့ခဲ့သော ID များကို ချက်ချင်း စစ်နိုင်သည့်ပုံစံဖြင့် မှတ်ထားပါ။ List ထဲတွင် အကြိမ်တိုင်း ရှာလျှင် အဆိုးဆုံး N² / 2 ≒ 2×10¹⁰ ကြိမ် ဖြစ်နိုင်သည်။

解説

HashSet<String> は「入っているかどうか」を平均 O(1) で調べられます。

seen.add(id) は、すでに入っていたら false を返します。これを使うと、調べて追加するのが 1 行で書けます。

if (!seen.add(id)) {   // 2 回目
    System.out.println(id);
    return;
}

List.contains は先頭から順に探すので O(N) です。名前は似ていても速さがまったく違うことを覚えておきましょう。

解説 (en)

A HashSet<String> checks "is it already in?" in O(1) on average.

seen.add(id) returns false when the ID was already there, so checking and adding fit in one line.

List.contains searches from the start and is O(N). The method names look alike, but the speed is completely different.

解説 (my)

HashSet<String> သည် «ပါပြီးသားလား» ကို ပျမ်းမျှ O(1) ဖြင့် စစ်နိုင်သည်။

seen.add(id) သည် ပါပြီးသားဖြစ်လျှင် false ကို ပြန်ပေးသဖြင့် စစ်ခြင်းနှင့် ထည့်ခြင်းကို တစ်ကြောင်းတည်းဖြင့် ရေးနိုင်သည်။

List.contains သည် အစမှ အစဉ်လိုက် ရှာသဖြင့် O(N) ဖြစ်သည်။ နာမည်ဆင်တူသော်လည်း မြန်နှုန်း လုံးဝကွာပါသည်။

解答 (Java)

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Set<String> seen = new HashSet<>();
        for (int i = 0; i < n; i++) {
            String id = sc.next();
            if (!seen.add(id)) {
                System.out.println(id);
                return;
            }
        }
        System.out.println("NONE");
    }
}
