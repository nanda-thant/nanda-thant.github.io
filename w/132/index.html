たいきけい taiki kei

Standby system

standby · secondary · failover node

အဓိကစနစ် ပျက်လျှင် အစားဝင်ရန် အသင့်ထားသော စနစ်

例文Examplesဥပမာ ဝါကျများ

  • 障害しょうがい時じは待機系たいきけいに自動じどうで切きり替かわります。

    In a failure, it automatically switches to the standby system.

    ပြဿနာဖြစ်ရင် standby system ကို အလိုအလျောက် ပြောင်းသွားပါတယ်။

  • 待機系たいきけいのサーバーも定期的ていきてきに確認かくにんします。

    We also check the standby server regularly.

    standby server ကိုလည်း ပုံမှန် စစ်ဆေးပါတယ်။
