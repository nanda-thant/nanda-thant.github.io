Memory leak

အသုံးမပြုတော့သော memory ကို ပြန်မလွှတ်ဘဲ တဖြည်းဖြည်း များလာခြင်း

例文Examplesဥပမာ ဝါကျများ

  • 長時間ちょうじかん動うごかすとメモリリークが起おきます。

    There's a memory leak when it runs for a long time.

    အချိန်ကြာကြာ run ရင် memory leak ဖြစ်ပါတယ်။

  • メモリリークの原因げんいんはキャッシュの解放かいほう漏もれでした。

    The memory leak was caused by a cache not being released.

    memory leak ရဲ့ အကြောင်းရင်းက cache ကို မလွှတ်မိလို့ပါ။
