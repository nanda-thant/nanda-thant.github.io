し指てき摘

してき shiteki

Review comment

feedback · point raised

ပြန်လည်သုံးသပ်စဉ် ထောက်ပြသည့် အချက် (ပြင်ရန်အချက်)

例文Examplesဥပမာ ဝါကျများ

  • レビューでいただいた指摘してきをすべて反映はんえいしました。

    I've applied all the review comments I received.

    review မှာ ရခဲ့တဲ့ ထောက်ပြချက်အားလုံးကို ပြင်ဆင်ထည့်သွင်းပြီးပါပြီ။

  • 指摘してきありがとうございます。すぐに直なおします。

    Thanks for pointing that out. I'll fix it right away.

    ထောက်ပြပေးလို့ ကျေးဇူးတင်ပါတယ်။ ချက်ချင်း ပြင်ပါမယ်။
