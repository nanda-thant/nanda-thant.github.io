りんぎ ringi

Approval request (internal)

ringi · formal approval process

ကုမ္ပဏီအတွင်း တရားဝင် ခွင့်ပြုချက် တောင်းခံသည့် လုပ်ထုံး

例文Examplesဥပမာ ဝါကျများ

    Buying a new tool requires a formal approval request.

    tool အသစ်ဝယ်ဖို့ တရားဝင် ခွင့်ပြုချက်တောင်းခံဖို့ လိုပါတယ်။

    It takes about a week for the approval request to go through.

    ခွင့်ပြုချက် ကျဖို့ ၁ ပတ်လောက် ကြာပါတယ်။
