Logical deletion

soft delete

    This table uses a delete flag for logical deletion.

    ဒီ table က delete flag နဲ့ logical deletion လုပ်ထားပါတယ်။

  • 論理削除ろんりさくじょされたデータは一覧いちらんに表示ひょうじしません。

    Soft-deleted data isn't shown in the list.
