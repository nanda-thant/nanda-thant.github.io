とつごう totsugou

Reconciliation (comparing data)

cross-check · matching

ဒေတာနှစ်ခုကို တိုက်ဆိုင်စစ်ဆေးခြင်း

例文Examplesဥပမာ ဝါကျများ

  • 移行いこう前後ぜんごのデータを突合とつごうして差異さいがないことを確認かくにんしました。

    We reconciled data before and after migration and confirmed there were no differences.

    ရွှေ့ပြောင်းမှု မတိုင်ခင်နဲ့ ပြီးနောက် data ကို တိုက်ဆိုင်စစ်ဆေးပြီး ကွာခြားမှု မရှိကြောင်း အတည်ပြုခဲ့ပါတယ်။

  • 請求せいきゅうデータと入金にゅうきんデータを突合とつごうします。

    We reconcile billing data with payment data.

    ငွေတောင်းခံ data နဲ့ ငွေလက်ခံ data ကို တိုက်စစ်ပါတယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

日常にちじょう会話かいわではほぼ使つかわないが、移行いこうやテストでよく使つかう。

Rare in daily speech, common in migration and testing.

နေ့စဉ်စကားမှာ မသုံးသလောက်ဖြစ်ပေမဲ့ data ရွှေ့ပြောင်းမှုနဲ့ test မှာ အသုံးများတယ်။
