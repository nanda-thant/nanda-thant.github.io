せいぞう seizou

Programming (phase)

coding phase · development

ပရိုဂရမ်ရေးသည့် အဆင့် (ဂျပန် IT တွင် coding ကို ဆိုလို)

例文Examplesဥပမာ ဝါကျများ

  • 製造せいぞうフェーズは来月末らいげつまつまでです。

    The programming phase runs until the end of next month.

    coding phase က နောက်လကုန်အထိ ဖြစ်ပါတယ်။

  • 製造せいぞうが終おわったら単体試験たんたいしけんに入はいります。

    After coding, we move to unit testing.

    coding ပြီးရင် unit test ကို စပါတယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

工場こうじょうの「製造せいぞう」ではなく、開発かいはつ工程こうていの「プログラミング」の意味いみ。経歴書けいれきしょの作業さぎょう範囲はんいにもよく出でる。

Not factory manufacturing: it means the programming phase, and appears in résumés.

စက်ရုံထုတ်လုပ်မှု မဟုတ်ဘဲ programming အဆင့်ကို ဆိုလိုတယ်။ ကိုယ်ရေးမှတ်တမ်း (経歴書) ထဲမှာလည်း မကြာခဏ ပါတယ်။
