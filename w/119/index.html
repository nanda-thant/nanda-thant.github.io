cron · scheduled run

例文Examplesဥပမာ ဝါကျများ

    It runs every hour on a schedule via cron.

    cron နဲ့ နာရီတိုင်း အလိုအလျောက် run ပါတယ်။

    အချိန်မှန် run တဲ့ schedule ကို ပြောင်းခဲ့ပါတယ်။
