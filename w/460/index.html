タイムゾーン

たいむぞーん taimu zoon

Time zone

timezone · JST · UTC

ဒေသအလိုက် စံတော်ချိန်

例文Examplesဥပမာ ဝါကျများ

  • タイムゾーンの違ちがいで日付ひづけが1日にちずれています。

    The date is off by one day because of the time zone difference.

    time zone ကွာခြားမှုကြောင့် ရက်စွဲ တစ်ရက် လွဲနေပါတယ်။

  • サーバーのタイムゾーンは日本にほん時間じかんに設定せっていしています。

    The server's time zone is set to Japan time.

    server ရဲ့ time zone ကို ဂျပန်အချိန် သတ်မှတ်ထားပါတယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

日本にほんは「JST」(UTC+9)。サーバーがUTCで動うごいていて日付ひづけがずれるバグはよくある。

Japan is JST (UTC+9); date bugs from servers running in UTC are common.

ဂျပန်က 「JST」(UTC+9)။ server က UTC နဲ့ run ပြီး ရက်စွဲ လွဲတဲ့ bug မကြာခဏ ဖြစ်တယ်။
