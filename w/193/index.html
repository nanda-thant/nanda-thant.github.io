よこてんかい yoko tenkai

Applying a fix elsewhere

rolling out horizontally · apply to similar places

တစ်နေရာတွင် တွေ့သော ပြဿနာ/ပြင်ဆင်မှုကို အလားတူ နေရာများသို့ ပါ အသုံးချခြင်း

例文Examplesဥပမာ ဝါကျများ

  • 同様どうようの不具合ふぐあいが他ほかの画面がめんにもないか横展開よこてんかいして確認かくにんしてください。

    Please check other screens for the same defect too.

    အလားတူ ချို့ယွင်းချက် တခြား screen မှာလည်း ရှိမရှိ ချဲ့ပြီး စစ်ဆေးပေးပါ။

  • 今回こんかいの対策たいさくをほかのチームにも横展開よこてんかいします。

    We'll apply this measure to other teams too.

    ဒီဖြေရှင်းချက်ကို တခြားအဖွဲ့တွေမှာလည်း ကျင့်သုံးပါမယ်။

A common on-site word: check whether the same bug exists elsewhere and fix it there too.
