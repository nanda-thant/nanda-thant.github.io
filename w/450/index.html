スレッド

すれっど sureddo

Thread

ပရိုဂရမ်အတွင်း တစ်ပြိုင်နက် လုပ်ဆောင်နိုင်သော လုပ်ငန်းစဉ် အစိတ်အပိုင်း

例文Examplesဥပမာ ဝါကျများ

  • この処理しょりは別べつスレッドで実行じっこうされます。

    This processing runs on a separate thread.

    ဒီလုပ်ဆောင်ချက်က သီးခြား thread မှာ run ပါတယ်။

  • スレッドの数かずを増ふやしても速はやくなりませんでした。

    Adding threads didn't make it faster.

    thread အရေအတွက် တိုးလည်း မမြန်လာခဲ့ပါဘူး။
