いち一じ次たい対おう応

いちじたいおう ichiji taiou

First response

first-line support · initial response

ပြဿနာဖြစ်ချိန် ပထမဆုံး လုပ်ဆောင်ရသော တုံ့ပြန်မှု

例文Examplesဥပမာ ဝါကျများ

  • 夜間やかんの一次対応いちじたいおうは運用うんようチームが行おこないます。

    The operations team handles first response at night.

    ညဘက် ပထမတုံ့ပြန်မှုကို operation အဖွဲ့က လုပ်ပါတယ်။

  • 一次対応いちじたいおうで解決かいけつしない場合ばあいは開発かいはつチームに連絡れんらくします。

    If the first response doesn't solve it, we contact the dev team.

    ပထမအဆင့် ကိုင်တွယ်မှုနဲ့ မပြေလည်ရင် development အဖွဲ့ကို ဆက်သွယ်ပါတယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

手順書てじゅんしょ通どおりに一次対応いちじたいおうし、解決かいけつしなければ二次対応にじたいおう(開発かいはつチーム)へエスカレーションする。

Follow the runbook for first response; if unresolved, escalate to second line (the dev team).

လုပ်ထုံးလုပ်နည်းအတိုင်း ပထမတုံ့ပြန်ပြီး မဖြေရှင်းနိုင်ရင် ဒုတိယအဆင့် (development အဖွဲ့) ကို escalate လုပ်တယ်။
