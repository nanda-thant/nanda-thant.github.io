Test specification

test spec · test plan

စမ်းသပ်မည့် အကြောင်းအရာ၊ လုပ်ဆောင်ပုံနှင့် မျှော်မှန်းရလဒ်များကို ရေးထားသော စာရွက်စာတမ်း

例文Examplesဥပမာ ဝါကျများ

  • 結合けつごう試験しけんの試験仕様書しけんしようしょを今週中こんしゅうちゅうに作成さくせいしてください。

    Please create the integration test specification by the end of this week.

    ပေါင်းစပ်စမ်းသပ်မှုအတွက် စမ်းသပ်ချက်စာတမ်းကို ဒီအပတ်အတွင်း ရေးပေးပါ။

  • 試験仕様書しけんしようしょの期待値きたいちが間違まちがっていました。

    The expected value in the test specification was wrong.
