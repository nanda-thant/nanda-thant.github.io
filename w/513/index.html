Proxy

proxy server

ကွန်ရက်ချိတ်ဆက်မှုကို ကြားခံပေးသော server

例文Examplesဥပမာ ဝါကျများ

  • プロキシの設定せっていをしないとライブラリがダウンロードできません。

    You can't download libraries without setting the proxy.

    proxy setting မလုပ်ရင် library download လုပ်လို့ မရပါဘူး။

  • プロキシ経由けいゆでインターネットに接続せつぞくします。

    We connect to the internet through a proxy.

    proxy ကနေတဆင့် internet ကို ချိတ်ပါတယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

客先きゃくさきではプロキシ経由けいゆでしか外部がいぶに出でられないことが多おおく、環境かんきょう構築こうちくでつまずきやすい。

Client sites often only allow outside access through a proxy, which trips up environment setup.

ဖောက်သည်ရုံးမှာ proxy ကနေသာ အပြင်ကို ထွက်လို့ရတာ များလို့ environment setup မှာ ခက်ခဲတတ်တယ်။
