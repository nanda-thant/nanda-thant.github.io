ハッシュか化

はっしゅか hasshu ka

Hashing

hash

data ကို ပြန်ဖော်မရသော တန်ဖိုးအဖြစ် ပြောင်းခြင်း

例文Examplesဥပမာ ဝါကျများ

  • パスワードはハッシュ化かして保存ほぞんします。

    Passwords are stored hashed.

    password ကို hash လုပ်ပြီး သိမ်းပါတယ်။

  • ハッシュ化かした値ちは元もとに戻もどせません。

    A hashed value can't be turned back.

    hash လုပ်ထားတဲ့ တန်ဖိုးကို မူလအတိုင်း ပြန်မရနိုင်ပါ။
