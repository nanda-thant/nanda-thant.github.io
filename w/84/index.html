Concurrency control

locking · exclusive control

လုပ်ငန်းစဉ်များက ဒေတာတစ်ခုတည်းကို တစ်ပြိုင်နက် ကိုင်တွယ်ရာတွင် ပဋိပက္ခမဖြစ်အောင် ထိန်းချုပ်ခြင်း

例文Examplesဥပမာ ဝါကျများ

  • 同時どうじ更新こうしんを防ふせぐために排他制御はいたせいぎょを入いれます。

    We add concurrency control to prevent simultaneous updates.

    တစ်ပြိုင်နက် update မဖြစ်အောင် concurrency control ထည့်ပါမယ်။

    Without concurrency control, data gets overwritten.
