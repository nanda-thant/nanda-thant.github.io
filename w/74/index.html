Batch processing

batch job · batch

ဒေတာ အများအပြားကို သတ်မှတ်အချိန်တွင် စုပြီး လုပ်ဆောင်ခြင်း

    This batch job runs every day at 2 a.m.

    ဒီ batch process က နေ့တိုင်း ညနက် ၂ နာရီမှာ run ပါတယ်။

    The batch processing didn't finish by morning.

    batch processing က မနက်အထိ မပြီးခဲ့ပါဘူး။
