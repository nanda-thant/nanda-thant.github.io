じょうほうろうえい jouhou rouei

Data leak

information leak · data breach

အချက်အလက်များ အပြင်သို့ ပေါက်ကြားခြင်း

例文Examplesဥပမာ ဝါကျများ

  • 情報漏洩じょうほうろうえいが起おきると、会社かいしゃの信用しんようを失うしないます。

    A data leak costs the company its trust.

    data ပေါက်ကြားမှု ဖြစ်ရင် ကုမ္ပဏီရဲ့ ယုံကြည်မှု ဆုံးရှုံးပါတယ်။

  • 情報漏洩じょうほうろうえいを防ふせぐため、USBメモリは使用しよう禁止きんしです。

    To prevent data leaks, USB sticks are not allowed.

    data ပေါက်ကြားမှု ကာကွယ်ဖို့ USB memory သုံးခွင့် မရှိပါဘူး။
