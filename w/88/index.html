Specification change

spec change · change request

မူလ သတ်မှတ်ချက်ကို ပြောင်းလဲခြင်း

例文Examplesဥပမာ ဝါကျများ

  • お客様きゃくさまから仕様変更しようへんこうの依頼いらいがありました。

    We received a spec change request from the customer.

    ဖောက်သည်ဆီက spec ပြောင်းလဲမှု တောင်းဆိုချက် ရောက်လာပါတယ်။

  • 仕様変更しようへんこうの影響えいきょうを調しらべて、工数こうすうを見積みつもりもります。

    We'll check the impact of the spec change and estimate the effort.

    spec ပြောင်းလဲမှုရဲ့ သက်ရောက်မှုကို စစ်ပြီး လုပ်အားကို ခန့်မှန်းပါမယ်။

現場ではOn siteလုပ်ငန်းခွင်တွင်

「仕様しよう変更へんこう」は工数こうすうや納期のうきに影響えいきょうするので必かならず報告ほうこくする。

Always report spec changes: they affect effort and deadlines.
